# AIオートドラマ

**現在開発中の実験的なプロジェクトです。まだ安定して利用できる状態ではありません。**

インストール手順もまだまとめられていません。

世界観や主人公のアイデアをもとに、台本・画像・音声をAIで生成し、一本道のビジュアルノベルを制作するアプリを目指しています。

生成途中でのエラーや停止、物語の品質・整合性などに課題があり、実用に向けて試行錯誤しています。

現在は、RTX5090(32GB)のローカル環境で3章構成(1章あたりの尺はオートモードで約10分)で出力が可能なことを確認済みです。

## 想定する使い方

1. 世界観や主人公などを指定します。
2. 提案された世界観とメインキャラクターの姿・声を確認し、必要があればAIに修正指示を出します。
3. 承認すると、脚本・背景・台詞音声などの制作が進みます。
4. ティラノスクリプト形式で出力し、完成した章から鑑賞が可能です。

開発者向けの情報は [開発ガイド](DEVELOPMENT.md) を参照してください。
