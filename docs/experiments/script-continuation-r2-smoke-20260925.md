# 台本継続 revision 2 の実装と小規模確認

2026-09-25。[初版3章レビュー](script-continuation-review-20260925.md)で見つかった、人物の過去の立場の取り違え、後続場面の先取り、説明中心の進行に対する入力改善を実装した。

- 構成・執筆に、変化を実際の選択と行動から描き、元の立場を反転させない指示を追加。
- 章間メモは、実際の行動と結果、拒否と受容、変わらない価値観・未決事項、到達点、未実施の予定を分ける。重要な判断に人物ID付きの短い原文を添える。メモは自然文のままで、合否検査や引用ID照合を増やしていない。

- 章計画に具体的な試み、相手の反応、そこから必要になる判断を示し、同じ議論や結論だけの場面を増やさない指示を追加。
