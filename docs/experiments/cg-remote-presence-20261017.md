# 画面越しの人物がイベントCGの部屋にも立つ問題（2026-10-17）

「凪の島の電波塔、嵐の夜のささやき」第1章の、ビデオ通話のイベントCG。生成計画は5回とも陽葵を「スマホの画面の中」に置いたが、5枚中3枚で陽葵が海斗の部屋にも立っていた。
CGのプロンプトに「その場にいない人物」を伝えると、どこまで防げるかの実験。製品のコードは変えていない。

## 結論

- 伝え方を変えると、部屋にも立つ失敗は15枚中9枚から4枚に減った。うまくいっていた構図は崩れなかった。
- 通話の無い場面のプロンプトは変わらず、描き直しても保存画像とピクセル単位で一致した。
- それでも確実ではない。部屋の奥まで写る構図では、参照画像の人物を配置しようとする画像モデルの癖が勝つことがある。
- 残る失敗をさらに減らす案（画面越しの人物の参照画像を胸像に切り抜く）は、今の画像モデルの癖に合わせた調整になるため見送った。

## 原因

CGのプロンプトは、参照画像の人物すべてに「The referenced characters stand on the same ground as their surroundings」と付けている。画面の中にいるという指示と矛盾し、陽葵の全身の参照画像も海斗と同じ扱いで渡される。

## 方法

`scripts/story/probe_cg_remote_presence.py`。保存済みのCG生成計画に残る構造化された指示から、プロンプトを2通りに組み立て直した。

- current: 現行のプロンプト
- presence: その場面で台詞が全て通信の声の人物（演出注釈の `remote`。立ち絵が登場しない人物と同じ判定）に「この場所には物理的にいない。画面などの指示された場所にだけ映す」と書き足し、「同じ地面に立つ」をその場にいる人物だけに限ったもの

画像は製品のCG生成処理（Qwen-Image、8ステップ、1536×1024）で描いた。

## 結果

保存済みの全47枚（9作品）のうち、プロンプトが変わるのは第1章の通話CG5枚だけだった。

| 計画 | 構図 | current で部屋にもいる | presence で部屋にもいる |
| --- | --- | ---: | ---: |
| c250 | 横顔の中景 | 0/3 | 0/3 |
| f6db | 寄り | 0/3 | 0/3 |
| 2d94 | 引き | 3/3 | 0/3 |
| 864f | 引き | 3/3 | 2/3 |
| 8740 | 背後からの中景 | 3/3 | 2/3 |
| 合計 | | 9/15 | 4/15 |

各計画で、保存済みのシードとその+1・+2を描いた（保存済みシードのcurrentは保存画像）。
対照として、プロンプトが変わらない4枚（凪の島 第3章、モノノケ・レゾナンス、ひだまり1年1組、星屑の境界線）を保存済みのシードで描き直し、4枚とも保存画像と完全に一致した。
