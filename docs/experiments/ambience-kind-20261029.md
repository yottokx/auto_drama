# 説明文から環境音の種類をLLMが選べるか（2026-10-29）

環境音ライブラリの実験2。実験1（`ambience-loops-20261029.md`）では、種類を正しく指定すれば4つのやり方で自然なループが作れると分かった。ここでは、ライブラリに追加する音の説明文から、LLMがその種類を選べるかを試した。製品のコードは変えていない。

## 条件

- モデル: Gemma 4 31B UD Q4_K_XL、推論なし。製品の最新のBGM計画プロファイルを使い、コンテキストは16k。
- 組: a（seed 20261029）と、その再実行 b（seed 20262029）。
- 説明文: 79件。BGMと環境音の注釈実験（`outputs/music-ambience-*`、35章）でLLMが場面ごとに書いた音の説明を、重複を除いて集めた（約350件）。そこから音ごとに1件を選び、試作ライブラリの名前を足した。音楽と、音ではないもの（霧、舞う桜など）は除いた。
- 1件ずつ、単独で聞いた（ライブラリに1件追加する時と同じ形）。
- 答えの形: `over_a_minute`（1分間に何が聞こえるかを1文）を書いてから、`kind` を4つから選ぶ。
  - continuous: 一様に続く
  - swell: 寄せては返す
  - ticks: 規則的に刻む
  - occasional: 時々起きる
  
  プロンプトでは種類を音のふるまいだけで定義し、音の例は挙げていない。
- 正解: こちらで付けた。説明だけではふるまいが決まらないもの（鳥のさえずりは群れの合唱か単発の声か、など）は、複数の種類を可とした。
- コード: `scripts/audio/probe_ambience_kind.py`。テスト: `tests/unit/test_probe_ambience_kind.py`。出力: `outputs/ambience-kind-20261029/`（`index.html` が一覧、`summary.json`）。

## 結果

| | a | b |
|---|---|---|
| 形の失敗 | 0 | 0 |
| 可とした種類に入った | 73/79 | 71/79 |
| 第一の正解と一致 | 65/79 | 64/79 |
| 「ずっと続く／時々聞こえる」の2択で合っていた | 76/79 | 77/79 |
| 2回の実行で同じ種類 | 70/79 | |

### 外れの中身

**2択を外したもの（a 3件、b 2件）。** 鳴らし方が大きく変わるので、一番問題になる外れ。

- 焚き火のはぜる音 → 時々起きる（a・bとも）。1分間の文は「薪が燃える音を背景に、時折パチパチとはぜる」。
- 夜風の音（a）、静かな夕方の空気（a）、無線機の激しいノイズ（b） → 時々起きる。いずれも1分間の文に「時折」が入っている。

どれも、ずっと鳴っている土台の上に、細部が時々加わる音。LLMは土台より細部に引っ張られて「時々起きる」を選んでいる。こう選ばれると、実際には土台が消えて、パチパチだけがぽつぽつ鳴ることになる。

**続く音の中での取り違え。** 害は小さい。

- 風を「寄せては返す」にした: 隙間風（a・b）、冷たい強風（b）、不自然に激しい風（b）。ほかに、モノノケの高周波振動（a）、兵士たちの歓声（b）。理由はどれも「強弱を繰り返しながら」。突風の合間の弱い所でつなぐことになるので、ループとしてはおそらく破綻しない。ただし試していない。
- 荒れた海を「一様に続く」にした（b）。
- 障壁への連続的な打撃音を「一様に続く」にした（a・b）。b の1分間の文は「一定のリズムの打撃音」なのに、選んだのは一様に続く。

## わかったこと

- 2択（ずっと続く／時々聞こえる）なら、ほぼ選べる（79件中76〜77件）。外れは「土台＋時々の細部」という一つの型に偏っている。
- 4択の中の細かい区別（とくに風と波）は、実行ごとに揺れる（同じ答えは79件中70件）。
- 外れの型ははっきりしている。対策の候補は、種類の定義に一般的な規則を足すこと。「下でずっと鳴り続ける音があり、時々加わるのは細部だけなら、続く音として選ぶ」。特定の音の例は入れない。まだ試していない。
- 製品では判定結果を画面に出し、ユーザーが変えられる設計にしている。なので、残った外れはそこで直せる。

## v2: 土台の規則を足す

種類の定義の最後に、一般的な規則を1文足した（`--criteria v2`）。「下でずっと鳴り続ける音があり、時々加わるのが細部だけなら、鳴り続ける方で判断する。時々起きる、は出来事の合間に音がまったく止まるものだけ」。特定の音の例は入れていない。説明文・シード・モデルは v1 と同じ。出力: `outputs/ambience-kind-v2-20261029/`。

| | v1 a | v1 b | v2 a | v2 b |
|---|---|---|---|---|
| 可とした種類に入った | 73 | 71 | 77 | 75 |
| 第一の正解と一致 | 65 | 64 | 72 | 70 |
| 2択で合っていた | 76 | 77 | 79 | 78 |
| 2回の実行で同じ種類 | 70 | | 77 | |

- 焚き火・夜風・夕方の空気・無線のノイズは、2回とも「一様に続く」になった。風を「寄せては返す」にする外れも無くなった。
- 新しく出た外れ（副作用）:
  - モノノケの咆哮が「一様に続く」になった（b）。1分間の文は「不気味な唸り声が続き、時折激しい咆哮が混ざる」。説明に無い土台を、LLMが自分で想像して足している。2択を外したのは v2 ではこの1件だけ。
  - 波が「寄せては返す」から「一様に続く」に流れた（荒れた海は a・b とも、穏やかな波は b）。続く音どうしの取り違えなので、2択には影響しない。質感のやり方で波をループした時に自然かは、実験1では試していない。
- 障壁への連続的な打撃音は、v1 と同じく「一様に続く」のまま。

ユーザーが試聴して直す前提なら、v2 で十分に実用になる。外れはほぼ「続く音どうしの取り違え」だけになり、試聴すればすぐ気づける。
