## 実装

- 自由長文 `conversation_space` を最大4件の `conversation_topics` へ変更。登録済み人物2〜3人、話題と関係の側面を各最大120文字、章のroleは最大200文字とした。固定3出来事・可変配分とも同じ指示・項目を使う。
- キャスト・出来事・配分は簡潔な計画回答を依頼。各話約10分という作品規模を知らせつつ、本文約4,000字・台詞約2,000字の目安は章計画で配分し、執筆へ渡す。本文の短縮や字数合否判定は行わない。
- 回答枠の既定は配分2,048、章計画6,144、執筆8,192 tokens。モデル・工程設定で変更可能。Gemma reasoningなし・16kを既定とし、既存のコンテキスト拡張設定も保持。
- 配置の生成形式をstage・already_done・adjustで分岐。通常配置には置換欄を生成させず、実施済みの場面番号0はコードで補う。内部の既存台本契約へ投影する。
- 過去の発言者enumを登場実績・承認設定の集合へ限定。未来のキャストと混同しない。
- 会話欄の任意文字位置での切断を撤去。原文の境界を守る履歴選択と遠い未来の省略は記録付きで維持。場面執筆に重複していた当章の行動列・後続場面の長い演出説明を整理。
- plot-onlyを作品同一性から外し実行段階へ移動。`--plot-only --resume`は本文に進まず、`--resume --chapter-limit 1`で保存プロットから執筆を開始できる。
- 送信前の失敗は別記録にし、生成修正の回数を消費しない。受信した構造エラーは応答と具体的な検証例外を保存。再開でも修正最大1回を維持し、途中で切れた計画を追加生成せず停止する。
