# 計画にいない人物の声と、場面の配役（2026-10-16）

「凪の島の電波塔、嵐の夜のささやき」で、無線の祖父の声が主人公（海斗）の台詞になった。
祖父はキャラクターとして存在せず、章計画の配役にもいなかった。本文の書き手は配役のIDしか話者に使えないため、別の人物のIDを借りた。
この問題への対策を比べた実験と、採用した対策、残した課題の記録。

## 結論

- 章計画に人物を足させる工夫（項目順・指示文・推論）では、計画は人物を足さなかった。
- 計画の後に「場面ごとに声が聞こえる人物」を挙げさせる軽い呼び出しを1回足す案（案1）を採用した。未定義の声は別の呼び出しで人物として作る。作った人物も既存の人物も、声が聞こえるのに配役にいない場面へ配役する。
- 最初の実装は未定義の声だけを配役していた。再生成では第1章で祖父が作られたが、第2章では祖父が既存の人物になっていて、声のチェックは s3 の祖父を正しく挙げたのに配役されず、無線の祖父の4行が湊の台詞になった。案1で作った人物は次の章から必ず既存の人物になるため、既存の人物も同じ規則で配役するよう直した（追加の呼び出しは無い）。
- 案1が拾えるのは計画に書かれた声だけ。本文の段階で出てくる一言は拾えない。そのうち既存キャラが地の文で済まされるケースを課題として残す（後述）。

## 実験

対象は保存済みの章計画の依頼12件（10作品）。`gemma-4-31B-it-UD-Q4_K_XL`、コンテキスト16,384。

| 方法 | 結果 |
| --- | --- |
| 計画の項目順を変え、人物の追加を場面より後に決めさせる | 12件中、人物の追加0 |
| 項目順＋指示文で声だけの人物の追加を促す | 0 |
| 推論を有効にする | 0 |
| 推論＋項目順 | 0 |
| 案1: 計画の後に、場面ごとの声を挙げる呼び出しを足す | 凪の島の第1章 s1・第2章 s4 で祖父を検出し、人物として定義できた。他の10件で誤検出なし |
| 案2: 本文の書き手に `VOICE[呼び名]: 本文` を許す（9場面） | 祖父は書けたが、誤用が2件（その場にいる人物の過去の姿、画面に表示される文字） |

参考: 保存済みの章計画で `new_characters` が空でなかったのは、推論なしで240件中0件、推論ありで13件中1件。

案1の費用は、声を挙げる呼び出しが1章あたり入力約1,000・出力約300トークン（全作品にかかる）。人物を作る呼び出しは、未定義の声があった章だけ1人あたり入力約5,800・出力約500トークン。

実装は `services/worker/generation/script_voices.py` と `ScriptRun.cast_heard_voices`。実験に使ったスクリプトは `scripts/story/probe_plan_new_characters.py`、`probe_scene_voices.py`、`probe_unplanned_voices.py`。

## 課題: 配役にいない既存キャラが地の文で済まされる

計画が配役から外した人物を本文で喋らせたくなると、書き手は他人のIDを借りるか、台詞を地の文に入れる。案1は前者のうち計画に書かれた声だけを防ぐ。

生成済みの全267場面（重複を除く）で、地の文の中に「」付きの発話があるものを拾った。大半は心の声・書面・看板の文字で、実際の発話を地の文に入れていたのは次の2件。

| 作品 | 場面 | 内容 |
| --- | --- | --- |
| 凪の島の電波塔、嵐の夜のささやき | 第1章 s1 | 録音された祖父の声を地の文の中に書いた（祖父は未定義。案1の対象） |
| ひだまり1年1組 | 第3章 s2 | 凛花（メインキャラ）が先を歩きながら独り言を言い、振り返って二人を呼び止める。s1・s3では配役されているが、s2の計画は陽葵と紬の2人だけ。計画の必須イベントに凛花は出ないため、案1でも拾えない |

`」` なしの言い換え（「村長に頼まれた」など）はこの拾い方では見つからないため、実数はもう少し多い可能性がある。

扱いは保留とした。理由は次の2つ。

- 地の文になっても物語は成立していて、失うのは立ち絵と声の演出だけ。明確な例は1件しかない。
- 原因は計画時の配役が控えめすぎることで、「サブキャラを作らなさすぎる」問題と同じ根にある。配役の決め方を見直すときにまとめて扱う。モデルの判断力で減る部分もありそうだが、計画が漏らすと書き手はそのIDを使えない、という構造は残る。

再確認の方法: `services/worker/cache/m2/jobs/*/*/script/sources/*.raw.txt` の `NARRATOR:` 行から `「…」` を含むものを抜き出し、「と言う・叫ぶ・呼ぶ・囁く」などの発話の動詞、または「声が響く」などを伴う行を読む。
