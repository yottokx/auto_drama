# 演出付けに渡す資料を絞る実験（2026-10-13）

[LLM入力の冗長表現の評価](llm-input-redundancy-20261013.md) の項目1を、実生成で確かめた記録。アプリのコードと設定は変更していない。実験用のスクリプト2本を追加した。

## 結論

- 入力は1回あたり平均33%減った。出力は約6%減、所要時間は約1割減にとどまる。
- 生成品質に、良い方向にも悪い方向にも、はっきりした差は無かった。
- 直前の発話を足す版にも、はっきりした改善は見られなかった。
- 評価は「効果: 大」から「効果: 中」に下げる。時間はほとんど縮まらず、演出付けの入力はもともと上限に遠い。
- 別の問題が見つかった。現行の入力でも、まとまりの約半分で、内心と声の出し方が英語で返っている。

## 方法

過去5作品から1場面ずつ選び、保存済みの演出付けの入力（設定・計画・発話）を取り出して、次の4通りで生成し直した。指示文とスキーマは、4通りとも現在の製品コードから取っている。

| 版 | 内容 |
| --- | --- |
| 現行 | 製品と同じ入力。場面の設定の全体と、脚本家向けのシステム指示 |
| 別シード | 現行と同じ入力で、シードだけ変えたもの。版の違いと偶然の揺れを見分ける基準 |
| 資料を絞った版 | 登場人物の設定と声、登場人物同士の関係、場所、計画だけ。世界設定は題名・ジャンル・雰囲気のみ。システム指示は演出付け用の短いもの。計画から分量の目安を除く |
| 直前の発話を加えた版 | 資料を絞った版に、同じ場面の直前8発話を参考として足したもの。場面の最初のまとまりには無い |

- 作品: モノノケ・レゾナンス、鉄と血の叙事詩、ひだまり1年1組、午前2時、コンビニに魔王が来た、終電のあとにだけ開く遺失物取扱所
- 規模: 17まとまり・140発話（うち台詞92）、計63回の生成。すべて形式の検証を通過した
- モデル: `gemma-4-31B-it-UD-Q4_K_XL`、reasoning none、コンテキスト 16,384、temperature 0.65
- 現行と各版は、まとまりごとに同じシードで比べた

## トークンと時間

1回あたりの平均。

| 版 | 入力 | 出力 | 所要秒 |
| --- | ---: | ---: | ---: |
| 現行 | 4,797 | 1,023 | 21.0 |
| 別シード | 4,797 | 1,022 | 18.2 |
| 資料を絞った版 | 3,222 | 963 | 19.3 |

直前の発話を加えた版は、対象の12まとまりで入力が平均 3,546。同じ12まとまりの現行は 4,649、資料を絞った版は 3,081。

- **入力**: 33%減。事前の見立て（6割以上が設定）より小さい。見立ての元にした1件は発話が4件の短いまとまりで、通常の10件のまとまりでは発話と指示文の比重がもっと大きい。
- **時間**: 別シードは直前の現行と同じ入力なので、入力がすべてサーバーに残っていて読み直しが無い。その差（約3秒）が、現行の入力を読むのにかかる時間にあたる。資料を絞って縮むのはその半分ほどで、1回あたり1〜2秒。所要時間の大半は出力の生成にかかっている。
- **出力**: 6%減は、内心の記述が短くなった分（平均8.0文字から6.6文字）。

## 生成品質

### 現行との一致率（台詞の行）

| 比べた版 | 声の感情 | 表情 |
| --- | ---: | ---: |
| 別シード（偶然の揺れ） | 75% | 84% |
| 資料を絞った版 | 73% | 75% |
| 直前の発話を加えた版 | 72% | 79% |

声の感情は、シードを変えただけの揺れと同じ程度しか動いていない。表情は揺れより少し多く動いた。

### 動いた行の読み比べ

現行と資料を絞った版で、声の感情か表情が食い違った台詞は41行あった。どちらの版か分からない並びにして読み、どちらが場面に合うかを判定した。

| 判定 | 行数 |
| --- | ---: |
| 資料を絞った版のほうが合う | 4 |
| 現行のほうが合う | 5 |
| どちらも妥当、またはどちらも不適切 | 32 |

差が付いた例:

- **現行のほうが合う**: 仲間の身を案じる台詞（モノノケ・レゾナンス）で、資料を絞った版は声を angry にした。現行は surprised。
- **資料を絞った版のほうが合う**: 事務的に淡々と話す人物の台詞（遺失物取扱所）で、現行は声を sad にした。資料を絞った版は neutral。

世界設定や登場しない人物の情報を外したことで読みを誤った、と言える行は見つからなかった。判定は1人（この記録の作成者であるAI）によるもので、音声と立ち絵に反映した結果は確かめていない。

### 傾向の比較

| | 現行 | 別シード | 資料を絞った版 |
| --- | ---: | ---: | ---: |
| 声の感情が neutral の台詞 | 50% | 40% | 37% |
| 表情が neutral の台詞 | 14% | 16% | 15% |
| 演出（注目・間・暗転・表情変化）の数 | 141 | 144 | 152 |
| 内心が英語だけの発話（140中） | 60 | 73 | 91 |
| 声の出し方が英語だけの台詞（92中） | 28 | 39 | 42 |
| 内心が既定値「未指定」のままの発話 | 4 | 3 | 0 |

- 演出の量や種類の偏りに、版による違いは無い。同じ演出を大量に繰り返すような異常も、どの版にも無かった。
- **英語の混入**: どの版でも、まとまり単位で内心と声の出し方が英語になることがある（現行で17まとまり中8、資料を絞った版で10）。資料を絞った版が最も多いが、現行と別シードの間にも同程度の開きがある。日本語の資料が減ると英語に寄りやすい可能性はあるが、この規模では偶然と区別できない。

### 直前の発話を加えた版

現行との一致率は資料を絞った版と同程度で、読み比べでも良くなったと言える行は見つからなかった。まとまりの境目で表情が途切れる問題が実際に減ったかは、この実験では測れていない。表情の指定は前のまとまりの出力に依存するのに、今回は直前の本文だけを渡し、前のまとまりで付けた表情は渡していない。

## 評価の更新

| | 事前の見立て | 実験後 |
| --- | --- | --- |
| 削減効果 | 大 | 中。入力は3分の1減るが、時間は1割弱しか縮まない |
| 悪い副作用 | 感情の読みが弱まりうる | この規模では見られなかった。英語の混入が増える可能性は残る |
| 良い副作用 | 直前の発話を渡せる | 本文を渡すだけでは改善を確認できなかった |
| 優先度 | 高 | 中 |

演出付けの入力は平均で約4,800トークンと、上限（16,384）から遠い。入力を減らしても収まるかどうかは変わらないので、利点は入力量と1回1〜2秒の時間に限られる。

## 別に見つかった問題

内心と声の出し方が英語で返る件は、資料の絞り込みとは別に、現行の入力で既に起きている。指示文は言語を指定していない。声の出し方の文言が音声の生成にどう使われるかは確かめていないが、日本語の作品で `slow and majestic` のような指定が混じるのは意図した動作ではないはず。

## 限界

- 5作品・各1場面・17まとまり。シードは各1組。
- モデルは1種類。推論ありの設定や別モデルでは確かめていない。
- 品質の判定は台詞の感情と表情の読み比べまで。音声・立ち絵・再生での見え方は確かめていない。
