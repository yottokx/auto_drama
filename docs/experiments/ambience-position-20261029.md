# 環境音が聞き手からどこで鳴っているかをLLMが判別できるか（2026-10-29）

注釈実験（`bgm-ambience-annotation-20261028.md`）では、屋内で雨や風が選ばれた場面がいくつもあった。そのまま鳴らすと、部屋の中で屋外の嵐が鳴る。逆に、窓の外を見ているだけの雨も鳴ってしまう。屋内か屋外かで分ける規則を作ると、例外が多すぎる。そこで、2つの判断で鳴らし方を決める案を立てた。この実験では、注釈実験で例に挙がった場面で、LLMがこの2つを正しく判別できるかを試した。製品のコードは変えていない。

- **位置**:
  - 同じ空間: 聞き手のいる空間で鳴る。壁や窓そのものが立てる音も含む。
  - 壁の向こう: 壁・窓・屋根・天幕越しに届く。
  - 機械の中: 無線・電話・録音から聞こえる。
- **示され方**:
  - 聞こえる: 本文がその音が聞こえる、またはどんな音かを書いている。
  - そこにある: 聞き手の周りで起きているが、音には触れていない。
  - 示されない: 見えているだけ、話題に出るだけ、または本文に無い。
- **鳴らし方**: 上の2つから機械的に決める。
  - 同じ空間で、聞こえるか、そこにある → そのまま鳴らす。
  - 壁の向こうで、聞こえる → こもらせて鳴らす。
  - それ以外 → 鳴らさない。

## 条件

- モデル: Gemma 4 31B UD Q4_K_XL、推論なし。製品の最新のBGM計画プロファイルを使い、コンテキストは16k。組は a（seed 20261029）と b（seed 20262029）。
- 例: 12場面の14音。場面の資料は `outputs/music-ambience-v5-20261028/a` から取った。
  - 入力: 場所の設定（名前・説明・時間帯・雰囲気）、その場面の全行、音の名前を1つ。1音ずつ聞いた。
  - 答えの形:
    - `where`: どこで鳴り、聞き手はどこにいるかを1文で書く。
    - `position`: 位置を選ぶ。
    - `shown`: 示され方を選ぶ。
    - `line`: 根拠の行。
- 定義は一般的な言葉だけで書き、例の場面の文は入れていない。
- 正解はこちらで付けた。2通りに取れるものは両方を可とした。
  - 凪の島 第1章の窓を叩く嵐は、同じ空間でも壁の向こうでもよい。
  - 行が音に触れていない雨や隙間風は、聞こえるでも、そこにあるでもよい。
- コード: `scripts/audio/probe_ambience_position.py`。テスト: `tests/unit/test_probe_ambience_position.py`。出力: `outputs/ambience-position-20261029/`（`index.html` が一覧）。

## 結果

a と b は、14件すべてで同じ答えだった。

| | a | b |
|---|---|---|
| 位置が合っていた | 12/14 | 12/14 |
| 示され方が合っていた | 11/14 | 11/14 |
| 鳴らし方が合っていた | 10/14 | 10/14 |

### 合っていたもの

- 部屋で聞く嵐・激しい雨・弱まる雨（凪の島 第1〜3章）は、壁の向こうで聞こえる → こもらせる。
  - 凪の島 第2章 s3 は、場所の設定が「沖の岩礁付近」だが、本文は部屋にいる海斗から書かれている。ここでも聞き手を部屋に置けた。
- 無線機から聞こえる風と波（凪の島 第2章 s2）は、機械の中 → 鳴らさない。
- 天幕で聞く外の風（鉄と血 第5章）は、壁の向こう → こもらせる。
- 路地の雨（境界の迷宮 第3章 s1・s3）、指令室の隙間風（鉄と血 第1章）、教室を吹き抜ける怪異の風（モノノケ 第1章）は、同じ空間 → そのまま。

### 外れたもの

- **見えているだけ、話題に出るだけの雨を「聞こえる」とした（2件）。** 壁の向こうの音として、こもらせて鳴ることになる。
  - カフェの小雨: 根拠は「窓の外では小雨が降り始め、街灯の光が濡れた路面を…」。`where` には「音はカフェの外から聞こえ」と書いた。
  - 古本屋の雨: 根拠は「カラン、と乾いたベルの音が鳴り、外の喧騒が遮断される」。雨の音には触れていない行。
- **無線機の中の波を、壁の向こうとした（1件）。** 凪の島 第2章 s3 の「激しい波の音が無線機を支配している」。同じ場面で、無線機の中の雨は正しく分けられている。
- **教室の「静かな風」を、教室の中を吹く風とした（1件）。** 本文の静かな風は窓の外の桜を揺らす風（u1）だが、同じ場面の不自然な風（u18）を根拠にした。音の名前だけを渡した、こちらの聞き方の問題が大きい。製品では、注釈の段階で根拠の行が付く。

## わかったこと

- **位置はほぼ判別できる。** 14件中12件で合い、場所の設定と聞き手の居場所が違う場面でも正しく判別できた。外れの1件は無線機の中の波で、もう1件は聞き方の問題。
- **「聞こえる」かの判別が弱い。** 見えているだけの雨、話題に出るだけの雨を「聞こえる」とする。音を1つ渡して聞く形そのものが、その音が鳴っている前提をLLMに与えている可能性がある。屋内の弱い雨を鳴らさないための判断なので、ここが外れると目的に届かない。
- 2回の実行は完全に一致したので、揺れではなく判断の偏り。
- 改善の候補（まだ試していない）: 根拠の行から、音を表す言葉をそのまま抜き出させる。抜き出した言葉が行に無ければ、その場で機械的に「示されない」とする。言い直しはさせない。見えているだけの行には音を表す言葉が無いので、有無だけを答えさせるより区別しやすくなる見込み。ただし、「小雨が降り始め」のような、雨の様子を表す言葉を抜き出してしまうおそれは残る。

## v2: 音を表す言葉を行から抜き出させる

v1 の改善候補をそのまま試した（`--criteria v2`）。根拠の行を選んだ後、「その音が聞こえる、またはどんな音かを書いた言葉」を行からそのまま写させ、その後で示され方を選ばせる。写した言葉が行に無ければ、機械的に「聞こえる」を「そこにある」に下げる。場面・シード・モデルは v1 と同じ。出力: `outputs/ambience-position-v2-20261029/`。

| | v1 a | v1 b | v2 a | v2 b |
|---|---|---|---|---|
| 位置が合っていた | 12 | 12 | 12 | 11 |
| 示され方が合っていた | 11 | 11 | 11 | 11 |
| 鳴らし方が合っていた | 10 | 10 | 10 | 9 |
| 2回の実行で同じ答え | 14 | | 13 | |

改善しなかった。直したかった2件は、モデルが雨そのものを表す言葉を「音の言葉」として写した。言葉は行に実在するので、機械的な照合も通ってしまう。v1 の記録で心配していた形がそのまま起きた。

- カフェの小雨: 「小雨が降り始め」（u2、窓の外の見た目の行）。
- 古本屋の雨: a は「激しい雨」（u8、佐伯の台詞）、b は「雨が降り続いている」（u27、地の文）。

写した言葉は、聞こえている行では「激しい雨音が絶えず響いている」「外の雨音は次第に弱まり」「空虚な風の音だけが鳴り響いていた」のように適切だった。ただし、音の言葉が無い行でも、雨や風の様子を表す言葉を写してしまう。空欄にしたのは、教室の風の2件だけだった。

ほかの変化:

- 無線機の中の波は、v1 と同じく壁の向こう。理由は「聞き手は船内にいる」に変わった。
- b で、凪の島 第2章 s3 の雨を同じ空間にした（「部屋に雨が降り注いでおり」）。v1 にはなかった外れ。

**わかったこと**: Gemma は「雨が降っていると書いた言葉」と「雨の音を書いた言葉」を区別していない。言葉を写させても、聞き方を変えただけでは、この区別は引き出せなかった。
