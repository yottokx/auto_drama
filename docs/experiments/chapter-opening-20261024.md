# 後の章の書き出しが前の章を繰り返す（2026-10-24）

開始条件をつなぎ直した後（`chapter-starts-20261024.md`）、本体で作り直したひだまり（ストーリーライン `f55c9ab4`、ガード付き）の第2章が、第1章の最後の場面の台詞をほぼそのまま写して始まった（約15行。写した1行は「きつくしimotoいいのに」と崩れた）。

## 原因

- 第2章以降の場面計画は、最初に `continuation`（前の章の最後を受けて、誰が最初に何を新しく行うか）を書き、それが第1場面の最初の出来事に【最初の新行動】として渡る（`script_chapter_plan.project_plan`）。
- このひだまりでは、`continuation` に当章の予定の開始条件（第1章の最後の手順の結果）がそのまま入った。結果の文が「凛花が『先生ー！』と泣きつき、氷室が正論で反論し始めるため、高岡先生は呆れて溜息をつきながらも、…安心する」と行動まで書いているので、本文はそれを新しい行動として演じ直した。第1場面の開始状態も「凛花が高岡先生に泣きつき、氷室がそれを正論でたしなめている状態」だった。
- 開始条件の実験でも、`continuation` が前の章の最後の一瞬をなぞる例は、修正の前後・作品を問わずあった。開始条件をつなぎ直しても、言い直す場所が変わるだけだった。

## 試した対策

どちらも実験用の設定（`ScriptOptions`、既定で無効。本体の作品には付かない）。

- A `opening_from_script`: 第2章以降、場面計画と本文に当章の予定の開始条件を渡さない（`script_opening_check.without_planned_start`）。後の出来事の開始条件と手順は残る。当章の始まりは保存済み台本の到達点だけから決まる。
- B `opening_replay_check`: 場面計画の後に、前の章の保存済み台本と、計画の書き出し（最初の新行動・第1場面の開始状態・第1場面の最初の出来事）を照合する短い依頼を1回出す。すでに起きた項目があれば、その項目と台本の引用を伝えて場面計画を1回だけやり直す。
