## 変更

revision 6の写真展では、同じ出来事の経路が「さらに急かす」、人物行動が「急かすのをやめて事情を聞く」と食い違い、章計画で後者が落ちた。この二重計画を整理した。

- 3章の全体計画は、開始条件と順序付きの `steps`（人物ID、行動、具体的結果）に統合する。結果を受けた次の人物の行動が選択を表す。独立したrouteや人物別転機は生成しない。既存表示用のrouteと転機要約は機械的に導出する。
- 章計画では、その章の行動に機械的に連番を付け、`placements` でどの場面に描くかを決める。通常の `stage` は元の行動・結果をそのまま既存ScenePlanの `required_events` へ投影する。LLMに別の人物行動一覧や到達点を生成させない。
- 実台本で済んだ行動は `already_done`、実績に合わせる変更は `adjust` とし、理由と変更内容を記録する。章計画には `step_placements` を保存し、執筆時の当章の未来資料は実施済みを除いた `realized_events` へ置換する。元の予定と調整後を同時に有効な指示として渡さない。
- 追加の実行・後始末は `follow_through` に明示する。全ての予定が既に実施済みでも、残る帰結を場面化できる。場面の終了状態・当章の到達点は、採用した最後の行動結果から導出する。
- 未来の経路調整も3章方式では新しい行動列を保存し、計画した章の完成後に次章の入力へ採用する。台本の過去と核心は書き換えない。
- 重要な発見を次の開始条件で先取りせず、試行と結果に含める。核心の完了目標は実際の履行まで計画する。場面を同じ主張の強調だけで増やさず、情報・結果・選択や場所・時間の変化で区切る。

検証は配分位置の欠落・重複・逆順、人物・場所参照、既存台本契約に限る。行動の意味や「実施済み」という判断の妥当性を自動判定する新たな意味検査はない。独立したLLM工程も増やしていない。位置番号は配分用で、原文引用IDではない。

話者ID付き台本、発話分離、演出、Script・Tyrano出力、Gemma・reasoningなし、可変コンテキスト予算を維持する。3章以外の従来計画経路は保持。通常UIへはまだ統合しない実験経路である。
