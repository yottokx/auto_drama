# 発話の渡し方とBGM入力の重複を減らす実験（2026-10-13）

[LLM入力の冗長表現の評価](llm-input-redundancy-20261013.md) の項目3（同じ本文の二重入力）と項目4（決めさせたい欄の既定値と文字位置）を、実生成で確かめた記録。アプリのコードと設定は変更していない。

## 結論

| 項目 | 入力 | 時間 | 品質 | 実験後の評価 |
| --- | --- | --- | --- | --- |
| 3. 演出付けで本文を1欄にする | 7%減 | 変わらない | 偶然の揺れの範囲 | 副作用は無い。効果は小。いつ入れてもよい |
| 3. BGMで本文を1通りにする | 22〜31%減 | 1〜2秒減 | 偶然の揺れの範囲 | 副作用は無い。効果は中 |
| 4. 既定値と文字位置を外す | 7%減 | 変わらない | 出力の傾向がはっきり変わる。良くなったとは言えない | 「副作用はほぼ無い」は誤り。単独では入れない |

- 項目4は事前の見立てが外れた。既定値を外すと、声の感情が neutral の台詞が50%から17%に減り、英語の応答が増えた。読み比べでは現行のほうが合う行が多かった。
- 項目3は見立てどおり安全だが、効果は見立てより小さい。演出付けの発話欄が入力に占める割合が、想定より小さかった。

## 演出付け: 方法

項目1の実験と同じ5作品・17まとまり・140発話（台詞92）を使い、次の3通りを追加で生成した。資料と指示文は現行のままで、発話の渡し方だけを変えている。現行・別シードの結果は項目1の実験のものを使った（同じモデル、同じ設定、同じシード）。

| 版 | 発話ごとに渡す欄 |
| --- | --- |
| 現行 | ID、話者、表示用本文、読み上げ用本文、文字位置2つ、内心「未指定」、声の感情「neutral」、声の出し方（空） |
| 本文1欄（項目3） | 現行から読み上げ用本文を除く |
| 既定値なし（項目4） | 現行から文字位置・内心・声の感情・声の出し方を除く |
| 最小（3と4の両方） | ID、話者、本文だけ |

51回の生成はすべて形式の検証を通過した。

## 演出付け: トークンと時間

1回あたりの平均。

| 版 | 入力 | 出力 | 所要秒 |
| --- | ---: | ---: | ---: |
| 現行 | 4,797 | 1,023 | 21.0 |
| 本文1欄 | 4,476 | 1,018 | 21.9 |
| 既定値なし | 4,449 | 1,012 | 20.7 |
| 最小 | 4,129 | 993 | 20.4 |

入力は各7%、両方で14%減る。出力と時間は変わらない。

## 演出付け: 生成品質

### 現行との一致率（台詞の行）

| 版 | 声の感情 | 表情 |
| --- | ---: | ---: |
| 別シード（偶然の揺れ） | 75% | 84% |
| 本文1欄 | 88% | 82% |
| 既定値なし | 55% | 73% |
| 最小 | 53% | 73% |

本文を1欄にしても、出力は揺れの範囲でしか動かない。既定値を外すと、声の感情が揺れを大きく超えて動く。

### 傾向の比較

| | 現行 | 別シード | 本文1欄 | 既定値なし | 最小 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 声の感情が neutral の台詞 | 50% | 40% | 47% | 17% | 18% |
| 声の感情が calm の台詞（92中） | 4 | 11 | 5 | 22 | 24 |
| 表情が neutral の台詞 | 14% | 16% | 15% | 16% | 14% |
| 内心が英語だけの発話（140中） | 60 | 73 | 78 | 108 | 100 |
| 声の出し方が英語だけの台詞（92中） | 28 | 39 | 38 | 55 | 50 |
| 内心が「未指定」のままの発話 | 4 | 3 | 0 | 0 | 0 |
| 内心の平均文字数 | 8.0 | 7.5 | 8.9 | 12.4 | 10.8 |

- **neutral への引っ張りは実在する**: 既定値「neutral」を見せないだけで、neutral の台詞が3分の1になる。現行で neutral だった台詞の行き先は、calm が約20行、surprised が5行、angry が3行。
- **表情は動かない**: 表情には既定値を渡していない。neutral の割合はどの版でも同じ。
- **英語が増える**: 内心が英語だけの発話は、現行と別シードで60〜73、既定値を外した版で100〜108。日本語の既定値「未指定」が、応答の言語の手がかりになっていたと見られる。
- **「未指定」の書き写しは消える**: ただし現行でも140中3〜4件と少ない。

### 動いた行の読み比べ

現行と最小の版で、声の感情か表情が食い違った台詞は56行あった。どちらの版か分からない並びにして読み、判定した。

| 判定 | 行数 |
| --- | ---: |
| 最小の版のほうが合う | 6 |
| 現行のほうが合う | 10 |
| どちらも妥当、またはどちらも不適切 | 40 |

- 40行の大半は neutral と calm の入れ替わりで、台詞に対してはどちらも妥当。
- 最小の版のほうが合う例: 衝撃を受けた台詞の声が、現行は neutral、最小の版は surprised。
- 現行のほうが合う例: 自信を持って作戦を告げる台詞が3行続けて、最小の版では表情が confused になった。

neutral が減ったことは、この読み比べでは改善として現れていない。calm と neutral の違いが音声でどう聞こえるかは確かめていない。判定は1人（この記録の作成者であるAI）による。

## BGM: 方法

保存済みのBGMの入力（曲の方向性を書かせる要求）を、6作品から1件ずつ取り、次の5通りで生成し直した。計30回、すべて形式の検証を通過した。

| 版 | 内容 |
| --- | --- |
| 現行 | 各場面に、台本の本文と発話一覧の両方がある |
| 別シード | 現行と同じ入力でシードだけ変えたもの |
| 発話一覧だけ | 台本の本文を除く |
| 台本だけ | 発話一覧を除く |
| 置き場所を1つに | 先頭の場面の本文と発話一覧を、まとまりの側にだけ残す |

5つ目は実験の準備中に見つけた重複。BGMの入力では、先頭の場面が単独の欄とまとまりの欄の両方に入っている。場面が1つのまとまりでは、同じ場面の本文が形を変えて4回入る。

## BGM: 結果

1回あたりの平均。

| 版 | 入力 | 出力 | 所要秒 |
| --- | ---: | ---: | ---: |
| 現行 | 8,516 | 224 | 8.7 |
| 発話一覧だけ | 5,884 | 235 | 6.8 |
| 台本だけ | 6,603 | 240 | 7.0 |
| 置き場所を1つに | 6,153 | 232 | 6.6 |

6作品すべてで、5通りの出力（場面の解釈と英語の音楽指示）を読み比べた。

- ジャンル、主な楽器、雰囲気、テンポは、どの版でも同じ範囲に収まった。テンポの差は最大で10BPM。
- 場面後半の転換（混乱から発見へ、高揚から絶望へ）は、どの版でも音楽の展開として書かれていた。発話一覧だけの版は各場面の最初と最後の3発話しか持たないが、転換の取りこぼしは無かった。
- 版による違いは、別シードとの違いと区別できなかった。

実際に曲を生成して聴き比べてはいない。

## 評価の更新

- **項目3**: 「副作用はほぼ無い」を確認した。演出付けの効果は見立ての「中」から「小」に下げる。BGMは「中」のままで、先頭場面の置き場所の重複も同時に直せる。
- **項目4**: 優先度を「中」から「保留」に変える。入力の削減は7%で時間は変わらず、出力の傾向だけが大きく動く。入れるなら、応答の言語を指示文で指定することと、neutral と calm の違いが音声に与える影響の確認が先に要る。

## 限界

- 演出付けは5作品・17まとまり、BGMは6作品・各1件。シードは各1組、モデルは1種類。
- 音声・立ち絵・曲に反映した結果は確かめていない。
- 項目4の傾向の変化は大きく、偶然とは考えにくい。ただし「どちらが良いか」の判定は、行数が少なく1人の読みによる。
