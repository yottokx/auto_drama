# FLUX.3 Klein の試用: 本体には実装しない（2026-10-16）

**位置づけ**: 実験のみ。本体（main）には取り込まない。このブランチ（`experiment/flux3-klein`）は記録として残す。結論は保留で、立ち上げ直す条件は末尾に書いた。

編集用の画像モデルを Qwen-Image-2.1 から FLUX.3 Klein（ライセンスが良く、サイズも小さい）へ置き換えられるかを試した。

## 結論

採用は保留。表情は Qwen より明確に低く、衣装は不安定だった。調整で直るかは分からず、ここに労力をかけると開発が止まる。コミュニティの知見や大きな改造が溜まってから見直す。

## 結果

- **表情**（6人の立ち絵 × 笑顔・怒り・驚き、Qwen Turbo と比較）: 「Qwenより明確に低い」。弱いのではなく崩れる。アニメ顔に写実的な額や眉のしわが出る、波打つ幅広の眉、縦長の「o」の口、目が広がらないまま高く細い眉になる、ずらした編集結果を元画像に混ぜた場所で線が二重になる、が主な症状。
- **表情のプロンプト調整**: 固定の依頼表なので実行時のLLMは要らない。Gemma に書かせた依頼はしわを消したが、前髪の上にV字の眉を描いた。手書きの依頼（相対サイズ、既存の線を残す、眉は前髪の下）はしわと浮いた眉を消し、驚きの口も良くなったが、怒りは弱いままで、「目を大きく」と書くと男性の顔がギャグ調の目になった。調整は失敗を別の場所へ動かしただけだった。
- **衣装**（5ケース）: 「うまくいくことはあるが、かなり不安定」。希望どおりは5件中2件。丈の短いパーカーが全長で描かれる、膝丈のワンピースがドレスになる、立ち絵のポーズが変わる、などがあった。アルファは無く、出力は白背景。衣装シート（Anima が描く素材画像と同じ作り）から着せると5件とも従い、Qwen と同等になった。
- **イベントCG**（7ケース）: 構図と背景は保たれ、動きはより活き活きできる。ただし参照した立ち絵が持つもの（バッグのぬいぐるみや剣）をそのまま描き（Qwen は省く）、温かい映画的な光は弱い。複数参照の 1536x1024 では Turbo より遅い。
- **プロンプト**: Qwen 用の本番プロンプトを公式のアップサンプラー（klein-pup）で書き換えて渡した。公式の勧めは、短く直接の依頼をアップサンプラーへ渡し、編集では「対象・変更・残すもの」を挙げる形。Qwen 用の回避策は Klein 向けには調整していない。

## 再現の手順

重み（Klein BF16 とアップサンプラー）と実行環境は削除済み。

1. `services/worker/runtimes/flux3_klein` で `uv sync`（`pyproject.toml` と `uv.lock` だけが残してある）。
2. `python -m scripts.flux3_klein.prepare --model klein`（アップサンプラーは `--model pup`）で重みを取り直す。リポジトリはゲート付きなので、Hugging Face で利用許諾に同意し、トークンを用意しておく。
3. 比較に使った入力: `scripts/flux3_klein/` の `expressions.py` / `expression_requests.py`（表情）、`outfit_sheets.py`（衣装シート）、`turbo_cases.py`（Turbo との比較ケース）、`klein.py`（実行）。

結果の画像は `outputs/image-edit-tests/klein-expressions-20261016`、`klein-outfits-20261016`、`klein-outfit-sheets-20261016`、`klein-cgs-20261016` にある（リポジトリには入っていない）。

## 立ち上げ直す条件

コミュニティの調整手法や大きな改造が出て、表情の崩れと衣装の不安定さが目に見えて減ったと分かったとき。
