# 環境音のループを音の種類ごとに作る（2026-10-29）

環境音ライブラリの実験1。音の種類（一様な質感／周期のある音／規則的に刻む音／時々起きる出来事）をこちらで指定し、種類ごとのやり方で自然なループが作れるかを試した。説明文からLLMが種類を選べるかは、別の実験（実験2）で扱う。製品のコードは変えていない。

## 条件

- 音源: Stable Audio 3 Medium、`TrackType: SFX`、8ステップ。12種×3テイク。続く音は90秒、電車の通過は25秒。seed は `4000 + 10×番号 + テイク`。プロンプトは 2026-10-27/28 の試作で分かった書き方（質感と密度を書く、鳴ってほしくない物の名前を書かない、物がぶつかる面を書かない）に従った。
- 音量: 続く音は RMS 0.03 にそろえた。電車の土台は RMS 0.01、通過音は一番大きい1秒が RMS 0.04 になるようにした。
- コード: `scripts/audio/probe_ambience_loops.py`（`generate` で生成、`loop` でループ化と試聴ページ作成）。テスト: `tests/unit/test_probe_ambience_loops.py`。
- 出力: `outputs/ambience-loops-20261029/`。`index.html` で試聴できる（元の音源、ループを2周、つなぎ目の前後8秒ずつ）。数値は `results.json`。

## やり方

| 種類 | 対象 | 区間の選び方 | つなぎ方 |
|---|---|---|---|
| 一様な質感 | 雨3段階、風2段階、火、無線のノイズ、電車の土台 | 生成の頭と尾のフェードを除いた範囲で、30秒以上の区間を選ぶ。つなぎ目は、目立つ瞬間が無く、いつもの音量の所にする。区間内は、目立つ音が少なく、音量が安定している方を選ぶ。両端の音量と音色はそろえる。長い区間ほど良い | 等パワー（sin/cos）で3秒 |
| 周期のある音 | 穏やかな波、荒れた海 | うねりの谷から谷まで（30秒以上） | 等パワー。谷を中心に、周期の1/4（0.5〜2秒） |
| 規則的に刻む音 | 時計 | 周期を自己相関で求め、1刻みずつ追う。一定の刻みが続く所から、偶数個の刻みを取る（チク・タクの交互を保つため）。切るのは刻みの0.35周期前の静かな所 | 0.08秒以内 |
| 時々起きる出来事 | 遠くの電車 | 1テイクから、ピークの30dB下までの1回分を切り出す（頭1秒・尾2秒のフェード）。土台のループの上に、35〜75秒の間隔で、ばらばらの音量で置く（3分の場面を2つ） | — |

### 途中で直した点

最初の版には、こちらの作り方の不備が2つあった。

- **質感の音のつなぎ目が、音量の落ち込みや突発音の中に置かれた。** 目立つかどうかを周囲3秒との差で見ていたため、周りより静かな所が選ばれやすかった。無線のノイズ1では、4秒続く突発音の途中でつながっていた。つなぎ目の窓全体が、テイク全体のいつもの音量から外れていないことを条件に加え、区間内の音量のばらつきも点数に入れた。
- **時計の刻みを数え違えた。** 1回の刻みに、0.15〜0.2秒遅れの2つ目のクリックが入ったり入らなかったりするため、クリックの間隔を直接見ると周期が崩れていた。周期を先に求め、予想した時刻の近くで一番強いクリックを1刻みとして追うようにした。

## 結果（数値で分かる範囲）

| | 結果 |
|---|---|
| ループにできなかったテイク | 0/36。波の6テイクはすべて谷が見つかり、質感方式での代用は無かった |
| ループの長さ | 質感 30〜77秒、波 59〜80秒、時計 27〜84秒 |
| つなぎの間の音量の落ち込み（質感24ループの中央値） | 等パワー −0.8dB。BGM用のつなぎ方なら −2.2dB。どのループでも等パワーの方が浅い（差の中央値 1.4dB） |
| 時計 | 3テイクとも一定の刻みが取れた（周期 0.89／0.50／1.00秒、ばらつき約2.5%）。テイク内の速さの変化は±0.4%以内で、前回の試作のように速くなるテイクは無かった |
| 電車 | 3テイクとも、通過の山は1つ（切り出した長さ15〜18秒） |

### 生成された音そのものが一様ではない

90秒の中で、1秒ごとの音量が大きく動く。テイクの中ほどの範囲で、上位10%と下位10%の差を取った。

- 雨: 8〜15dB
- 風・火: 4〜16dB
- 無線のノイズ: 9〜19dB

雨は「しとしと」でも、10〜20秒ほどの強まりと弱まりを繰り返す。この強まりはループの中に残るので、ループの長さ（30〜77秒）ごとに同じ強まりが戻ってくる。区間の選び方では避けきれない。耳で聞いて一番確かめたいのはここ。

### 耳で確かめる点

数値では判断できないものを挙げる。

- **つなぎ目が分かるか。** 「つなぎ目」の音源（8秒目がつなぎ目）。
- **2周目で「同じ所」と気づくか。** とくに雨の強まり、火のはぜる音、無線のノイズの突発音。
- **波のうねりの周期。** 2.5〜4秒と検出された。実際の波としては短いので、谷として検出した所が本当に波の引き際か、もっと細かい揺れを拾っているのかを聞いて確かめる。
- **時計のつなぎ目でリズムがよろけないか。**
- **電車の場面の間隔と音量が自然か。**

### 聴感の判断

ユーザーが試聴ページを聞いて「問題無い」と判断した（2026-10-29）。種類を正しく指定すれば、この4つのやり方で自然なループが作れる。

## 今回やっていないこと

- 長さの違う2本を重ねる工夫と、鳴らし始めの位置を毎回変える工夫。長時間鳴らした時の繰り返しの問題で、まず1本のループが自然かを確かめてからにする。
- 生成した音の強まりを均す処理（ゆっくり音量をそろえる）。上の「一様ではない」の結果を聞いてから考える。
