# 章ごとの肉付けを足した3章・5章の比較（2026-10-20）

長尺化の実験（`long-form-20261019.md`）では、5章にしても出来事の連鎖が増えず、章が薄まった。そこで計画を2段にした。今の連鎖を骨組みとして作り、その後で章ごとに、その章の手順を足す（肉付け）。これを鉄と血の叙事詩の3章と5章で試し、前回の3章・5章（肉付けなし）と比べた。

## 条件

- 入力・モデル・設定は前回と同じ。鉄と血の叙事詩の承認スナップショット（`outputs/cast-size-20261017/inputs/tetsu-qat-product.json`）、gemma-4-31B-it-UD-Q4_K_XL、推論なし、32k、演出注釈なし、シードは入力のまま。
- スクリプト: `scripts/story/check_text_long.py --expand`。製品のコードは変えていない。
- 出力: `outputs/long-form-20261020/tetsu-ud-3ch-expand/`、`outputs/long-form-20261020/tetsu-ud-5ch-expand/`。前回の出力は `outputs/long-form-20261019/`。

### 肉付けの段

章への配分の後、第1章から順に1章ずつLLMに依頼する。

- 渡すもの: 全章の骨組み（題名・役割・手順）、肉付け済みの前の章、当章の骨組みの手順（番号付き）。
- 答えさせるもの: 当章に加える手順だけ。各手順を、骨組みのどの手順の後に置くか（`after_step`）と一緒に答える。骨組みの手順はコードがそのまま残すので、書き換わらない。
- 指示の内容:
  - 骨組みの手順へ至る試行・応答・発見や、サブ・脇の人物自身の用事・関心・対立による行動を加える。
  - 他の章の骨組みを先取りせず、前の章で済んだことや同じ主張の確認を繰り返さない。
  - 目安は、骨組みと合わせて当章が4〜6手順になる量。

章の場面計画以降は、肉付けした手順を予定として受け取る。それ以外は製品の流れそのもの。

## 6章（配分のバランス化と、肉付けの上限・言い換え禁止）

章数の判定実験（`chapter-count-judgment-20261020.md`）で鉄と血が6話と判定されたので、6章で台本まで生成した。条件は上と同じ（Gemma 推論なし、32k、演出注釈なし）。キャスト計画の指示文に章数が入るため、キャストと連鎖は3章・5章とは別のものになった（技師がリリアではなくリィア、マルクスは兵站管理の軍曹）。

### プロットの段階で直したこと

1. 最初のプロット（`tetsu-ud-6ch-expand`）は、連鎖の出来事9つのうち4つ（6手順）が最終章に配分された。肉付け後は5 / 5 / 5 / 6 / 5 / 9手順で、最終章だけが重い。
2. 配分のバランス化（`--balanced`）: 製品の3章用 `sized_allocation` を6章に広げた。コードが、出来事の切れ目で6章に区切るやり方を、各章の手順数のばらつきが小さい順に30通り挙げる。モデルはその中から、製品の指示文（「最終章に残りを詰め込まない」を含む）で選ぶ。
3. 肉付けの上限（`--expansion-steps 6`）: 1章が骨組みと合わせて6手順を超えないよう、足せる手順の数を回答の形式で制限した。
   - 2と3の結果（`tetsu-ud-6ch-balanced`）: 骨組み 2 / 2 / 2 / 3 / 3 / 1、肉付け後 5 / 6 / 6 / 6 / 6 / 4。モデルは、ばらつきが最小の区切りではなく、決着を第5章に置いて第6章を後日談にする区切りを選んだ。
4. 肉付けの言い換え禁止（`--distinct-steps`）: 3の時点で、第2章に「リィアが限界突破の調整を提案」と骨組みの「リィアが過負荷テストを提案」が並んだ。指示の「骨組みの手順へ至る試行」が、同じ行動の前振りを招いていた。そこで「骨組みの手順と同じ行動・提案・決定を、言い換えや前振りとして足さない。準備を足すなら別の人物か別の用事にする」と変えた（`tetsu-ud-6ch-distinct`）。肉付け後は 5 / 6 / 5 / 6 / 6 / 5手順で、骨組みの言い換えは見当たらなくなった。

### 案1から言えること

- 締めの落ちを防ぐ効果は、核心の文が無くても保てた（コンビニ2シード）。
