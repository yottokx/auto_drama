## 実装した内容

- 場面の相対分量から本文・台詞の目標を `scene_sizes` に保存し、同じ数値を本文指示と回答枠計算へ使用する。各章の既定4,000字・台詞2,000字を維持する。
- 場面の回答枠を目標量・話者IDと改行・安全係数・同モデルの既出実測から算出し、入力計測と実送信へ同じ `max_tokens` を渡す。推定根拠・採用値を送信前に保存し、再開時は再計算しない。上限到達からの続筆は既存どおり1回。
- 当場面の場所定義・終了状態の重複を除き、不在でも計画・接続方針で参照する人物と関係を残す。完全なキャスト・素材情報は元の保存データに維持する。削った入力の範囲と理由は診断メタデータに残す。
- 容量不足時も、各完了章の原文または本文由来メモを必ず保持。同章の既出原文は全文、直前完了章の末場面は原文で保持する。取得失敗や出典不一致のメモは代替にしない。遠い未来も章の目的・終点を残す。
- 3章プロット生成は冒頭の開始状態だけを生成し、後続の開始状態は直前の出来事の最後の結果から投影する。既存の保存・章配分・表示の形式を維持する。
- 章計画の `continuation` を今後の接続方針に限定し、実績欄として再要約しない。未発生の前提は経緯を場面に含めるよう指示する。意味の全件照合やLLM検査は追加しない。
- Gemma、reasoningなし、16k比較を維持。設定による32k・64kや回答枠拡張を妨げる固定上限は追加していない。モデル・KVキャッシュの量子化は変更していない。

通常UIではなく `script_continuation_v1` の独立した実験経路への実装。話者ID・NARRATOR、発話分離、演出、素材要求、Script/Tyrano出力を維持している。旧実験の設定・本文は変更していない。
