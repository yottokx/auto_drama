# イベントCGの構図・差分を改善できるかの実験計画

記録日: 2026-10-07（日本時間）

状態: 計画のみ。画像生成・コード変更は未実施。方針の一部は未決定（末尾に記載）。

現在のイベントCGは「二人を横から中距離で写した絵」に偏り、出す利点が薄い。原因の整理と改善方針の議論をここにまとめ、**最初に行う画像生成実験**の条件を定める。実験の目的は、LLM側を改修する前に、Qwenが立ち絵の参照から多様な構図と大きな差分を描けるかを確かめることである。

## 議論で確定した意図

以前の改修（[表示区間と差分の改善](../event-cg-staging-plan.md)、計画基準2）は、元の指摘を次のように狭く解釈していた。今回、本来の意図を確認した。

| 項目 | 元の指摘 | 基準2での解釈 | 本来の意図 |
| --- | --- | --- | --- |
| 表示期間 | CGがすぐ消える | 1枚あたり5発話以上を必須にする | 5発話でも短い。もっと長く見せる |
| 絵と本文の一致 | （指摘なし） | 表示中ずっと絵の状態が本文で成立していること | **表示中ずっと一致している必要はない** |
| 差分 | 1発話ごとに手の位置や涙の位置を変えるなら作る時間が無駄 | 差分は基本0枚 | 表示期間を伸ばし、**効果的な差分を作る** |

## 現状の観察

採用済みの基本CG2枚（計画基準1で生成）と、その画像指示を確認した。

| 章 | 場面 | 画像指示の `Framing` | 人物の `position` |
| --- | --- | --- | --- |
| 第1章 | 喫茶店で向き合い、透が訴える | （横からの中距離） | left / right |
| 第2章 | 駅入口で透が美緒の手首を掴む | `Medium shot, side view of the confrontation` | right / left |

[第1章の画像](assets/qwen-event-cg-appearance-20261004/chapter-1-original.png)、[第2章の画像](assets/qwen-event-cg-appearance-20261004/chapter-2-original.png)とも、目線の高さで真横から、二人を左右に同じ大きさで収めている。第2章は手首を掴む動作があるのに、カメラは第1章と同じである。**動作の有無より、カメラと人物配置が毎回同じことが単調さの主因**と見ている。

計画基準2の試行（画像は未生成）では、3章とも差分0枚で、選ばれた区間も「柱のそばに並んで立ち線路を見る」「椅子に座ってスマホを見る」という動きのない状態になった。

## 原因の仮説

| # | 原因 | 該当箇所 | 確度 |
| --- | --- | --- | --- |
| 1 | 画像指示の形式に構図の語彙がない。カメラは自由記述の `framing` 1個だけで、人物は全員同じ形式の `position / action / expression`。主役と脇役、前景と後景、背中向き、画面外を表せない | [event_cg_visuals.py](../../services/worker/generation/event_cg_visuals.py) の `schema` | 指示の実物で確認済み |
| 2 | 固定の末尾文が「全員の顔・髪・服・体型を保つ」「顔をメッセージ枠より上に」を常に要求し、後ろ姿・手元の寄り・極端な俯瞰やあおりと両立しにくい | 同 `compile_images` | 推測。実験で確認 |
| 3 | 参照画像が正面の立ち絵なので、Qwenが立ち絵を並べる方向へ寄る | 参照の与え方 | 推測。実験で確認 |
| 4 | 選定が「表示中ずっと成立する状態」を要求し、姿勢や接触の変化でCGを終了させるため、動かない区間が選ばれる | [event_cg_staging.py](../../services/worker/generation/event_cg_staging.py) の `SYSTEM` | 基準2の試行結果と一致 |
| 5 | 差分は「0枚を優先」、変更範囲は「表情・視線・小さな仕草のみ」に限定されている | 同上、および `event_cg_visuals.py` の差分用固定文 | 指示文で確認済み |
| 6 | CGごとに独立して計画するため、作品内で構図が重複しても検知できない | [event_cg_pipeline.py](../../services/worker/generation/event_cg_pipeline.py) の `plan_cgs` | コードで確認済み |

「多様でインパクトのある構図にせよ」という文章を足すだけでは、1〜3と6が残るため改善しないと判断している。

## 改修方針の案（計画基準3）

実験結果で範囲を決める。現時点では実装方式として確定していない。

1. **CGは場面を象徴する一枚として扱う。** 最も絵になる瞬間を描き、余韻も含めて場面の終わり近くまで表示する。「表示中ずっと絵が本文と一致」の制約と、安全な終了境界の申告は廃止する。
2. **残す制約は二つ。** 描かれた出来事が本文で起きる前には出さない（先取りの禁止）。描かれている人物が退場したらCGを終了する。
3. **差分は区間内の転機ごとに使う。** 「0枚を優先」をやめ、発話ごとの微差には使わない、という本来の制限だけを残す。変更範囲を光・時間・小物、姿勢・接触まで広げられるかは実験で決める。カメラが変わる場合は差分ではなく、隣接する別のCGとして連続させる（区間の隣接は現行の検証でも通る）。
4. **構図を選択式の語彙にする。** ショットサイズ、カメラ角度、主役の人物、人物ごとの奥行き（前景・中景・後景）と向き（正面・横・背中・一部のみ）を列挙型にし、作品内で使用済みの組み合わせをコードで弾く。固定の末尾文は構図に応じて切り替える。
5. **選定に「絵としての見どころ」を必須にする。** 立ち絵と背景では表現できないものを書けなければ0枚にする。

入退場は、台本の演出指示（`enter` / `exit`）から各発話時点の登場人物をコードで計算して扱う。現在の選定にはこの情報を渡していない。

| 状況 | 扱い |
| --- | --- |
| 描かれている人物が退場する | その発話でCGを終了。コードで強制 |
| 描かれていない人物が入場して話す | 許容。長く居座る場合だけ終了を検討 |
| 描かれていない人物が最初から同席 | 許容 |

## 実験の問い

1. 立ち絵2枚の参照から、横からの中距離以外の構図を指示どおりに描けるか。
2. その際、キャラクターの同一性（髪、メガネ、服）を保てるか。
3. 固定の末尾文は、顔を見せない構図の妨げになっているか。
4. 基本CGを編集して、表情以外の変化（光・時間、姿勢・接触、人物の消去）を、背景とカメラを保ったまま描けるか。

## 実験A: 構図

立ち絵2枚だけを参照に、基本CGを新規生成する。完成済みCGは入力にしない。画像指示は手書きし、LLMは使わない。

対象は、動作のある場面（第2章、駅入口で手首を掴む）と、静かな会話の場面（第1章、喫茶店で向き合う）の2つ。後者は「動作がなくてもカメラだけで変化を出せるか」を見るために含める。

| 条件 | 構図 | 見たいこと |
| --- | --- | --- |
| A0 | 元の指示のまま再生成 | 今回の環境での基準。[外見追記実験](qwen-event-cg-appearance-20261004.md)で未実施だった再現性の確認も兼ねる |
| A1 | 肩越し。透の後頭部と肩を前景に、美緒の顔を主役にする | 背中向きの人物を描けるか。前景と後景の大小差 |
| A2 | 手元の寄り。掴まれた手首（第1章は机上の握り拳）を大きく、顔は画面外か一部のみ | 顔を見せない絵を描けるか |
| A3 | 俯瞰の引き。人物を小さく、場所を大きく | 人物が小さいときの同一性 |
| A4 | あおりで一人に寄る。美緒の顔を大きく、透は画面に入る腕だけ | 一人を主役にし、もう一人を部分だけにできるか |
| A5 | 奥行きの非対称。一人を画面端の前景に大きく横顔で、もう一人を奥に小さく | 左右対称の配置から外せるか |

A1〜A5は、構図に合わせて書き換えた末尾文を使う（例: 背中向きの人物には顔の保持を求めない）。問い3のため、A1とA2だけ「現行の固定文のまま」の版も第2章で生成する。

枚数は、6条件 × 2場面 × 2 seed = 24枚と、固定文の比較 2条件 × 2 seed = 4枚の計28枚。

## 実験B: 差分

採用済みの基本CGを参照1（`base_cg`）、立ち絵を参照2以降として編集する。現行の差分生成と同じ入力形式である。差分用の固定文（表情・視線・小さな仕草のみ変更）は、条件に合わせて手書きで置き換える。

| 条件 | 元の絵 | 変更 | 位置づけ |
| --- | --- | --- | --- |
| B1 | 第1章 喫茶店 | 美緒が目を伏せ、涙がこぼれる | 現行で許可されている範囲。基準 |
| B2 | 第2章 駅入口 | 夕暮れから夜へ。駅の照明が点く | 光・時間の変化 |
| B3a | 第2章 駅入口 | 手首を掴む → 透が美緒を抱き寄せる | 姿勢・接触の変化 |
| B3b | 第1章 喫茶店 | 透が机に突っ伏す、または美緒が透の拳に手を重ねる | 姿勢・接触の変化（座った場面） |
| B4 | 第2章 駅入口 | 美緒が去り、透だけが手を伸ばしたまま残る | 退場を差分で表せるか。任意 |

枚数は、5条件 × 2 seed = 10枚。

## 共通の生成条件

[外見追記実験](qwen-event-cg-appearance-20261004.md)と同じ方法と設定を使う。保存済みの生成依頼を複製し、`prompt` と、それに対応して再計算する `input_sha256` だけを変える（実験Bは参照の構成も差分用にする）。

| 項目 | 設定 |
| --- | --- |
| モデル | Qwen/Qwen-Image-2.1、revision `d26bb61231c349cf6b7896fa83353113880e1ba3` |
| 実行経路 | 既存のローカルDiffusersイベントCG backend |
| 精度など | BF16、量子化なし、CPUオフロード有効、KVキャッシュ有効 |
| 解像度・ステップ | 960×640、40ステップ |
| seed | 第1章 `1524320612`、第2章 `383775884` と、各章もう1つ。条件間でseedの組を揃える |
| 参照順序 | 画像1=水瀬 透、画像2=篠原 美緒（実験Bは画像1=基本CG、以降が人物） |

前回の実測は1枚あたり約75秒（モデルのロード込み）。38枚で最大50分程度、モデルを再利用できればそれより短い。GPUを占有するため、録画や制作ジョブが動いていない時間に実行する。

作品DB・公開CG・アプリの生成処理は変更しない。Coordinatorは起動しない。出力は新しい `outputs/` 配下のフォルダーに書き、比較に使う画像・完全な指示・生成記録を `docs/experiments/assets/` へコピーする。

## 評価

目視で、画像ごとに次を記録する。

| 項目 | 記録する内容 |
| --- | --- |
| 構図の適合 | ショットサイズ、カメラ角度、前景・後景、人物の向きが指示どおりか |
| 同一性 | 髪、メガネ、服、小物。見える・自然に隠れている・画角外・判定不能を分ける |
| 破綻 | 余分な人物、手や腕の異常、人物の混同 |
| 場面の読み取り | 誰が何をしている場面か、関係が伝わるか |
| メッセージ枠 | 主役の顔や見せたい部分が画面下部に隠れないか |
| 差分のみ | 背景・カメラ・服が基本CGと一致するか。変化がはっきり読めるか |

後ろ姿や手元の寄りでは、顔やメガネが見えないこと自体を失敗にしない。

暫定の判定基準として、ある条件の4枚（2場面 × 2 seed）のうち3枚以上が「構図が適合し、破綻がなく、同一性に矛盾がない」なら、その構図は使えると見なす。差分は2枚とも成立した条件を使えると見なす。枚数が少ないため、成功率の推定ではなく、改修に進むかどうかの判断材料として扱う。

## 結果による次の手

| 結果 | 次の手 |
| --- | --- |
| 構図の多くが使える | 構図の語彙を選択式にする改修（方針4）と、選定の改修（方針1・2・5）に進む。使えた構図だけを語彙に入れる |
| 現行の固定文の版だけ失敗する | 固定文の条件分けを改修に含める |
| 構図がほとんど出ない | LLM側の改修では解決しない。参照の与え方（顔の切り抜きを渡す、外見を文章で補う）を先に調べる |
| 姿勢・接触の差分が使える | 差分の変更範囲を姿勢・接触まで広げる（方針3） |
| 姿勢・接触の差分が崩れる | 差分は表情と光・時間までにし、姿勢の変化は隣接する別のCGで表す |
| 人物の消去が使える | 退場を「CG終了」ではなく差分で扱う選択肢を検討する |

## 未決定の点

- **山場より前からの表示。** ネタバレにならない絵なら山場より前から表示してよい（案A）か、常に出来事の時点から表示する（案B）か。案Aを仮の前提にしている。案Bは単純だが、山場が場面の終盤にあると表示が短くなる。
- **表示期間の目安。** 「原則その場面の残りを通して表示」を既定にする案だが、数値の目安や上限は決めていない。
- **入退場の演出指示の信頼性。** 地の文で退場が書かれているのに `exit` がない、といった食い違いがどの程度あるかは未確認。

## この実験で扱わないこと

- LLMによる選定・画像指示の品質。画像モデルの可否が分かってから、計画だけの再実行で比較する。
- 3人以上の場面、別作品、別キャラクター。
- メガネの欠落など外見の再現。[外見追記実験](qwen-event-cg-appearance-20261004.md)で継続する。ただし今回の画像でも同一性の欄に記録する。
