# 長い人物IDを短い別名に置き換える実験（2026-10-13）

[LLM入力の冗長表現の評価](llm-input-redundancy-20261013.md) の項目2を、実生成で確かめた記録。アプリのコードと設定は変更していない。実験用のスクリプト2本を追加した。

## 結論

- 場面本文では、入力が16%、出力が21%、所要時間が21%減った。書かれた本文の量は変わっていない。
- 演出付けと場面計画でも、入力が1〜2割、時間が約1割減った。
- 生成品質の低下は見つからなかった。形式の検証の通過数は現行と同じで、読んだ場面に話者の取り違えは無かった。
- 事前の評価（効果: 大、優先度: 高）を維持する。4項目のうち、時間が実際に縮むのはこの項目。
- 実装で守るべき点が1つ、実験の中で実際に問題になりかけた。別名を元に戻す処理は、語の境界を見る必要がある。

## 方法

過去5作品について、保存済みの入力を次の2通りで生成し直した。まとまりごとに同じシードを使った。

| 版 | 内容 |
| --- | --- |
| 現行 | 保存済みの入力のまま |
| 別名 | 入力・スキーマ・話者の文法に出る長いIDを `character-2` の形に置き換えて送り、応答を実IDに戻してから検証 |

- 作品: モノノケ・レゾナンス、鉄と血の叙事詩、ひだまり1年1組、午前2時、コンビニに魔王が来た、瑠璃色の境界線。どれも長いIDの人物が2人いる
- 工程: 場面計画（各作品1件）、場面本文（各2場面）、演出付け（各1場面の全まとまり）。計64回の生成
- モデル: `gemma-4-31B-it-UD-Q4_K_XL`、reasoning none、temperature 0.65
- コンテキストは 32,768。保存済みの場面本文の入力には 16,384 に収まらないものがあるため
- 別名は、その入力に出ていない番号を選ぶ。保存物には書き込まない

## トークンと時間

1回あたりの平均と、現行に対する減少率（組ごとの平均）。

| 工程 | 組数 | 入力（現行 → 別名） | 出力（現行 → 別名） | 所要秒（現行 → 別名） |
| --- | ---: | --- | --- | --- |
| 場面本文 | 10 | 14,088 → 11,854（16%減） | 1,279 → 999（21%減） | 27.4 → 21.5（21%減） |
| 演出付け | 17 | 4,886 → 4,359（11%減） | 1,083 → 916（13%減） | 21.1 → 18.3（12%減） |
| 場面計画 | 5 | 12,271 → 10,424（15%減） | 1,515 → 1,381（8%減） | 32.6 → 27.9（12%減） |

- **場面本文**: 本文の量は現行が平均1,256文字、別名が1,298文字で変わらない。本文1文字あたりの出力トークンは 1.02 から 0.77 に下がった。減った分は話者IDを書くのに使っていたトークン。
- **演出付け**: 出力が減るのは、注目や表情の演出に人物IDを書くため。
- **場面計画**: 出力の差は、場面数など内容の揺れのほうが大きい。5件では減少率を確定できない。

所要時間の大半は出力の生成にかかる。入力だけを減らした項目1では時間がほとんど縮まなかったのに対し、この項目は出力も減るので時間に効く。

## 生成品質

### 形式の検証

| 工程 | 現行 | 別名 |
| --- | ---: | ---: |
| 場面本文（話者・行の形式） | 10/10 | 10/10 |
| 演出付け（発話の対応、演出の参照） | 17/17 | 17/17 |
| 場面計画（登場人物IDが資料にあるか） | 3/5 | 3/5 |

場面計画の不合格2件は、現行・別名の両方で同じ作品に出た。登場人物の欄に `s1` `s2` と書いている。この2作品の保存済み入力は古い指示文で、「idはs1,s2など短くします」が登場人物の欄にかかるように読める。現在の指示文は「各sceneのid（場面ID）は」と直してある。別名とは関係がない。

現行の版で長いIDを写し間違えた例は、今回の64回には無かった。場面本文は文法で話者を制約しているので、写し間違いは起きない構成でもある。

### 場面本文の読み比べ

10場面のうち5場面（4作品）で、別名版の本文を読んだ。うち2場面は現行版と並べて読んだ。

- 話者の取り違えは無かった。地の文が名前で書く人物と、台詞の話者IDは一致している。
- 人物ごとの口調（魔王の尊大な口調、物静かな人物の短い返答など）は保たれている。
- 必須の出来事の消化や場面の終わり方に、版による傾向の違いは見られなかった。

同じシードでも本文は別の文章になるので、行ごとの比較はできない。判定は1人（この記録の作成者であるAI）による。

### 演出付けの一致率

現行と別名で、台詞94行の声の感情は86%、表情は89%が一致した。項目1の実験で測った、シードを変えただけの揺れ（声75%、表情84%）の範囲に収まっている。演出の種類と数にも違いは無い。

### 別名の漏れ

応答を実IDに戻したあと、別名が残った箇所は無かった。場面計画と演出付けで、自由文の中に人物IDを書いた応答も無かった。

## 実装で守るべき点

事前に挙げた注意点のうち、1つが実験中に実際に問題になりかけた。

- **語の境界**: 「瑠璃色の境界線」には `character-29a1…` で始まる実IDがある。別名 `character-2` を単純な部分一致で探すと、この実IDの先頭に一致する。実験の変換処理は前後の文字を見て置き換えているので誤変換は起きなかったが、集計側の単純な検査が6件を誤って検出した。本実装でも境界の確認は必須。

そのほかの注意点（別名は実IDと衝突しない番号にする、スキーマと文法の中のIDも置き換える、保存物は実IDのままにする）は、実験の変換処理で実際にそうしており、問題は出ていない。

## 限界

- 5作品、長いIDの人物は各2人。長いIDが1人や3人以上の作品では、効果の大きさが変わる。
- モデルは1種類で、推論なしの設定だけ。推論ありの設定では場面本文に文法の制約がかからず、長いIDの写し間違いが起きうる。その条件は確かめていない。
- 履歴メモ、プロット、キャスト計画など、ほかの工程では確かめていない。
- 品質の判定は、形式の検証と本文の読み比べまで。音声・立ち絵・再生での見え方は確かめていない。
