# 場面単位の無音をなくした章のBGM設計を、35章で確かめる（2026-10-29）

章のBGM設計を planning_version 3 に変えた。中身は次の3点。

- どの場面にもBGMを付ける。場面ごとの選択肢は play／continue だけで、stop は無い。
- 音楽を止めるのは、場面の途中の一瞬だけ（`music_drops`）。
- 止める行を答えられるように、各場面の全台詞を発話ID付きで渡す。

止める瞬間の基準は、注釈実験の v3 と同じにした（`bgm-ambience-annotation-20261028.md`）。注釈実験では環境音の判断と一緒に答えさせていたが、製品では BGM 設計の1回の依頼の中で答えさせる。この形でも同じ傾向になるかを、既存の35章で確かめた。

## 条件

- 製品の工程（`music_pipeline._chapter_decisions`、version 3）を、そのまま章ごとに1回呼んだ。新曲のプロンプト作成は呼んでいない。データベースには何も保存していない。
- 入力: 章ごとに最新の、章全体の `m3_music_plan` の依頼。注釈実験と同じ35章を使い、`planning_version` だけ 3 に変えた。
- モデル: Gemma 4 31B UD Q4_K_XL、推論なし。製品の最新のBGM計画プロファイルを使い、コンテキストは16k。seed 20261028 で1回実行した。
- コード: `scripts/story/probe_music_drops.py`。出力: `outputs/music-drops-v3-20261029/`（`index.html` で、止める行の前後を読める）。

## わかったこと

- 場面単位の無音は、回答の形の上で起きなくなった。
- 止める瞬間は、注釈実験より少なく、本文がはっきり静けさや死を書いている所だけが残った。どれも本文の重さに見合う。0件の章が32章あり、「止めないのがふつう」という基準どおりになっている。
- 減った理由は、まだ調べていない。候補は2つ。
  - 今回は1回だけの実行なので、ばらつきの範囲かもしれない（注釈実験は2回で6件と7件）。
  - 製品の工程では、作品全体の文脈（`story_context`）も一緒に渡しているので、判断が変わったのかもしれない。
- 入力は最大12,521トークンで、16kの段に収まる。注釈実験より約3,000トークン多い。製品の工程が作品全体の文脈も渡しているためで、回答に使える残りは約3,800トークンになる。

## ティラノでの確認

止める瞬間のある3章を、v3 の計画でティラノに組み直して確認した（ユーザー、2026-10-29）。

- 3章とは、凪の島 第2章、ステラ・ブリーズ 第2章、モノノケ・レゾナンス 第1章。
- 曲は再計画と同じ決まりで割り当てた。その場面の採用済みの曲、無ければその場面で前に鳴っていた曲を使う。
- 曲の無かったモノノケ 第1章の場面3は、計画のプロンプトから Stable Audio で生成した。

ユーザーの判断は次のとおり。

- **戻し方**: 止めた位置から約1.5秒かけて同じ曲を戻すのは、問題ない。
- **凪の島 第2章の止める位置**: 「世界から嵐の音が消えたかのような静寂」は s3-u7 の地の文にあるが、止めるのは次の祖父の台詞（s3-u8）の前。言われてみれば1行遅いという程度で、違和感は強くない。この1か所のために指示文を変えるほどではないので、そのままにする。
