# 人物の力関係から作るプロットと台本（2026-10-30〜11-01）

「詐術の檻：虚構の支配者たち」と「鉄と血の叙事詩」で、次の不満が出た。

- 駆け引きがない。
- 台詞で説明しすぎる。
- 舞が駒になる。
- ヴァレリウスが弱すぎる。
- 話に波がない。

原因を、モデルの性能ではなく、製品の作り方（ハーネス）の側で探した。主な原因は3つあった。

- プロットの手順が「行動→結末が必要とする結果」だけで書かれていて、相手側が自分の望みと知っていることから応じる余地がない。
- 章の場面計画の required_events が、台詞の中身や作戦会議・報告の手順をそのまま並べる。
- 人物ごとの望みや手段が、台本の段階まで届かない。

## 製品に入れたもの（2026-11-01）

| 項目 | 内容 | 設定 |
|---|---|---|
| プロット | 出来事の連鎖の前に、人物ごとの力関係（forces）を書かせる。望み・手段・最後の手（last_resort）・知らないこと・食い違いの5つ。各手順には、本人の狙い（aim）と、結果を知らないまま動く人物（hidden_from）を書かせる。対立は、本人の気づき・説得・撤退ではなく、最後の手が相手の手で通らなくなることで決着させる。負ける側の着地は、何を失い何を守ったかで書く。章への配分と章ごとの肉付けにも、力関係を渡す。 | `story_forces`（新しい計画で既定） |
| 章への配分 | 各章の番号と最後の出来事を、題名より先に書かせる。 | `story_forces` と同じ |
| 台本 | 章の場面計画と場面の執筆に、力関係を渡す（`forces`）。標準の `forces_unspoken` では、さらに場面ごとに「口に出さない本音」（unspoken）を書かせ、執筆には地の文で内心や効果を解説させない。 | `script_drama`（力関係のある計画を承認すると `forces_unspoken`） |

- 指示文と回答の形式は、実験で使ったもの（下の a3l、修正3、frcsub）と同じにした。
- 開発用の設定で、承認時に方式を選べる。`scripts/start-coordinator.ps1 -DevOptions`（`AUTO_DRAMA_DEV_OPTIONS=1`）で起動すると、STEP4 の承認ダイアログに「台本の方式（開発用）」が出る。選べるのは「力関係＋口に出さない本音（標準）」「力関係」「従来」の3つ。方式を1つに決めたら、この選択は消す。
- 既存の作品は、作ったときの方式のまま動く。
  - 力関係が入るのはプロットを作るときなので、作り直すときに入る。メイン設定を再承認して全体計画を作り直すか、章数を選ぶ前の計画で章数を選ぶと入る。
  - 力関係のない計画を承認すると、台本は従来の方式で作る。

## 実験

使ったモデルは Gemma 4 31B UD Q4_K_XL、推論なし。比べた作品は次の7つ。

- 詐術の檻（5章）
- 鉄と血（6章）
- 世界最後の一時間と、僕らの不完全な申請書（3章）
- 午前2時、コンビニに魔王が来た（3章）
- ひだまり1年1組（4章）
- モノノケ・レゾナンス
- 凪の島の電波塔、嵐の夜のささやき

出力は `outputs/plot-drama-20261030/` に置いた。作品ごとの比較は `report-<作品>.md` と `summary.md`、台本の比較は `script-arms-comparison.md` にある。

### プロット（`scripts/story/probe_plot_drama.py`）

| 条件 | 内容 | 結果 |
|---|---|---|
| base | 製品のまま | 知らない人がいる手順は0。対立は気づきや説得で収まる。 |
| a | 力関係を先に書き、手順に狙いと hidden_from を書く | 相手側が自分の望みで動く手順が出た。 |
| b | a で、結末（core）を出来事の後に書く | 結末が弱くなり、採らなかった。 |
| a2 | a に最後の手を足す。負ける側は最後の手まで使って負ける | 決着に抵抗が入った。 |
| **a3l** | a2 に、負ける側の着地の書き方を足す | 負けた側が「相手が正しかった」と認めて終わる型が消えた。**採用。** |
| a3i / a3s / a4 | 負ける側が一度相手を上回る手を、規則や欄で入れる | 後から「読んでいた」と取り消されたり、件数を埋めるだけの手になったりした。 |
| a5 | 主筋が争いかを作品ごとに判断し、争いなら勝つ側が失うもの（setbacks）を先に決める | 鉄と血では効いた（砦と精鋭を失ったまま進む）。詐術の檻では半分が「想定内」に戻された。争いなら逆転を入れる、という決まった型になるので保留。 |
| a3r | 手順ごとに、読者に見せる・伏せる・明かすを書かせる | 伏せた手順と明かす手順の対応は4件中1件だけで、効果が弱かった。 |

小説向けに調整したモデル（Gemma-4-Novelist-Eclipse-31B）も試した（`probe_writer_model.py`）。

- プロットでは、敵や脇役が自分から動く手順が増えた。ただし4回中2回で人物IDの取り違えがあった。
- Gemma が作ったプロットで第1章を書かせた結果は、Gemma と見分けがつかなかった。
- 推奨モデルにはしない。

### 章への配分（`scripts/story/probe_allocation_fix.py`）

鉄と血の連鎖（1手順の出来事が10個、6章）で、配分が失敗した。回答では題名と役割が最後の出来事より先にあり、モデルは出来事を1章に1つずつ割り当てて、残りを最終章に詰めた。

| 修正 | 内容 | 鉄と血 |
|---|---|---|
| 1 pick | 区切り方の番号だけを選ばせる | 改善はしたが不安定 |
| 2 code | 最も均等な区切り方をコードで決める | 確実だが、内容で区切らない |
| **3 order** | 番号と最後の出来事を、題名より先に書かせる | 11回中11回成功し、内容で区切られた。**採用。** |

修正3を他の作品でも試した。10か所の区切りのうち8か所は変わらず、変わった2か所も妥当だった。

### 台本（`scripts/story/probe_script_drama.py`、演出なし）

| 方式 | 詐術の檻の文字数 / 場面執筆の最大入力 | 内容 |
|---|---|---|
| now（従来） | 35.3k / 23.6k | 計画と報告の場面が多い。内面を地の文で説明する。 |
| sub | 38.1k / 24.9k | 見せる描写が増えた。駆け引きは増えない。 |
| frc | 47.2k / 29.5k | 駆け引きが一番強い（御門が舞の正体を暴く）。ただし長すぎる。 |
| frcl | 39.3k / 25.9k | 増加は小さいが、暴く場面が消えた。 |
| **frcsub** | 36.0k / 25.0k | 説明は sub 並みに少ない。frc の長さとトークンの増加はほぼ消えた。**標準に採用。** |

小さい作品（世界最後、コンビニ）とひだまりでは、どの方式でも文字数の増減は −10〜+10% で収まった。場面執筆の入力の増減も −1.0k〜+1.5k だった。

frcsub に残る弱い所は次のとおり。

- 詐術の檻の第1章に、打ち合わせ・報告の場面が残る。
- 九条が自分の手口を台詞で解説する。
- 作品によって長さが振れる。

どの方式も各作品1回ずつの生成なので、人が読んで評価するのはこれから。そのために開発用の選択を残した。

## 製品の工程での確認

世界最後を、製品の工程そのまま（`story_forces`、`script_drama=forces_unspoken`）で作った。条件は 16k、演出なし、キャストは `sekai-a3l` と同じ。出力は `sekai-product-16k/`。

- 3章とも最後まで書けた。文字数は 6.5k・7.3k・9.8k で、失敗による代替（fallbacks）はなかった。
- 力関係は3人分できた。口に出さない本音は12場面のすべてに書かれ、保存した場面計画には残っていない。
- 入力の最大は次のとおり（括弧内は上限）。

| 工程 | 入力の最大 |
|---|---|
| プロット（連鎖・肉付け） | 7,365（7,680） |
| 章への配分 | 6,380（13,824） |
| 章の場面計画 | 9,702（9,728） |
| 場面の執筆 | 13,773（13,824） |

- 第2・3章の場面計画と、第3章の場面の執筆では、そのままでは上限を超えた。製品の既存の仕組みで前の章の資料を縮め、上限に収めて送った。
- 力関係なしの同じ条件で、どれだけ縮めるかは測っていない。
