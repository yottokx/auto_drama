# M3当時の第1話とrevision 7の分量・会話の比較

2026-09-25。ユーザーの「当初想定は1話約10分、M3当時のオート約7分程度の分量は欲しい」という指摘を受けて確認した。今回の1話は1章に対応する。コードの実装変更・LLM生成・画像音声の再生成は行っていない。

## 結論

現在のrevision 7は、M3当時に比べて1話の分量が大幅に減っている。M3の10作品の第1話は本文2,360〜3,502文字、中央値2,861.5文字。r7は各話875・867・1,738文字で、平均1,160文字、M3中央値の約41%にとどまる。台詞文字数は平均約364文字で、M3中央値1,065文字の約34%。

r7の**3話合計3,480文字が、M3の長めの1話ほど**である。「夜明けの図書列車」は1話3,393文字、そのうち台詞1,623文字。r7は3話を合計しても台詞1,093文字しかない。

直前の計画で設定した「3章合計約7,000文字」は、縮小した最近の出力を参照した値で、当初の1話の尺を基準にしていなかったため撤回する。その値を3分割すると約2,333文字で、今回確認したM3の最短の第1話よりも少ない。**1話約10分を目指し、少なくともM3当時の内容量を確保する**という条件を、プロット前から扱う。

## 対象と測り方

- M4移行前のバックアップ `data/backups/before-m4-20260924-230103.db` にある公開済み9作品と、独立したM3検証用「夜明けの図書列車」の第1話を対象とした。
- 通常9作品は、バックアップ時点での各作品の最終公開版を使用。表示調整・修正版を重複して数えない。公開ZIP内の台本と保存済み本文の一致、成果物のSHA-256を確認した。同じ公開版の音声を集計した。
- 本文文字数は保存済み `raw_text` の非空行から、話者ID・コロン・前後空白・改行を除いた文字数。台詞は `NARRATOR` 以外の行。M3の表示本文文字数・読み上げ台詞文字数とも一致を確認した。
- 音声長は公開ZIPのWAVヘッダーから取得した合計。通常9作品で音声ファイル数と台詞行数の一致も確認した。地の文の表示、オート待機、場面転換の時間は含まない。
- **今回はオート再生時間を実測していない。** ユーザーが約7分と感じた特定作品の同定や、M3の全作品が約7分だったとの判断はしていない。r6/r7は音声なしなので、同条件の実再生時間は比較できない。

再集計用の[スクリプト](../../outputs/m3-r7-length-comparison-20260925/measure.py)、[詳細数値・出典](../../outputs/m3-r7-length-comparison-20260925/measurements.json)、各M3台本の読み取り用複製を保存した。元の作品・DB・公開ZIPは変更していない。

## 通読して分かる違い

### M3「夜明けの図書列車」

[旧台本](../../outputs/m3-r7-length-comparison-20260925/m3-library-train.md)では、1話の中に三つの違う会話のまとまりがある。

1. テオの賑やかな出迎えに、司書が皮肉で返す。砂の色、持ってきた本、マルガの関心を話してから、駅名の食い違いに気づく（9〜47行）。世界の説明と人物同士の調子が、応答の中にある。
2. 本を通行税にしようとする提案にマルガが異論を出す。記録と現地の風の音をめぐるやり取りを経て、検証を条件に停泊が許可される（57〜103行）。提案の提示だけで終わらず、複数の応答がある。
3. テオが金属片を持ってくる。司書の照合、テオの喜び、マルガの拒絶で同じ発見への反応が分かれ、次の調査への疑問が残る（109〜153行）。

二人のサブキャラはそれぞれ違う関心と口調を持ち、1対1から3人へ会話の組み合わせも変わる。ただし、駅名や風からの結論は飛躍があり、M3の整合性まで優れていたという評価ではない。

### M3の日常物と喜劇

[「陽だまり」の旧台本](../../outputs/m3-r7-length-comparison-20260925/m3-03.md)は、父の料理と娘の気遣い、娘が犬にだけ本音を漏らす場面、翌日のお裾分けに来た節子との会話を描く。相手が替わると前場面の「おいしい」の意味が変わって見える（9〜50行）。主題の説明を繰り返す以外の方法で、人物を知る時間を作っている。節子が父娘双方の問題を見抜く点には、便利な助言役へ寄る弱さもある。

[「魔王軍」の旧台本](../../outputs/m3-r7-length-comparison-20260925/m3-05.md)では、十二秒の遅刻を叱る掛け合い、魔法で眠気を抑えながら承認印を押す仕事、現場担当のゴルザスの事情が会話になる。攻略できる村がない、都市は危険、岩山では略奪できない、と現場側の問題が具体化する（13〜19、52〜62、88〜94行）。一方で、努力と数字の口論には反復もある。

### r7の写真展

[現在の台本](../../outputs/script-relationship-seed1-r7-smoke-20260925/story.md)は、配置を拒否する、情報を切り分ける、問いかけ札を作る、という主筋の判断と設営作業にほぼ全量を集中している。第1話の会話は14行、第2話は18行。作業中の気安さや、別の相手に見せる顔、人物自身の別の関心に触れる時間が少ない。

第3話の最後は、写真を押し当てる、端を整える、手を離す、下がる、消灯、歩く、閉扉、施錠を20行で描き、台詞は4行だけ（135〜154行）。所作の行数を増やしても、M3にあった会話の材料や人物を知る機会は増えない。

M3にもナレーター比率の高い作品がある。戻したいのは旧作の全ての長文や冗長さではなく、**1話の中で人物と過ごす量、相手の応答を受けて話が展開する量**である。

## 実装から分かる縮小の要因

M3にもr7にも、1話の字数・台詞数・再生時間を目標として渡す仕組みはなかった。M3は章概要から1〜3場面・場面ごとの複数イベントを展開していた。r7は主要行動を保持する代わりに、追加できる内容を絞り、割当行動の終了状態へ達したら止める指示を強めている。内容量の要求がないため、薄い計画でも短いまま完成できる。

M3「図書列車」の保存済み本文要求3件は各上限3,072tokensで、生成813・946・830tokens、いずれも正常終了。r7の本文要求6件の上限は8,192tokensだった。**本文出力枠を小さくしたことによる短縮ではない。** M3とr7では題材等も違うため、個々の指示がどれだけ影響したかまでは分離できない。

M3「図書列車」の第1話には、対比、食い違い、交渉、反証、発見、拒絶という会話を生む材料がある。r7は3話全体を7つの行動で構成し、札の記入・固定・施錠などの作業へ寄る。異なる定義のイベント件数を直接比べるより、各話にどれだけ応答や経験を生む材料があるかを見る必要がある。

## 計画への反映

[改善計画](../visual-novel-dialogue-cast-plan.md)を次の方針へ修正する。

- 単位を1話に戻し、約10分を目標、少なくともユーザーが望むM3当時の分量を確保する。3章合計の予算だけで満足しない。
- キャスト設計・全体プロットの前から1話の分量方針を渡し、各話に応答、試行、反応、日常や別視点の材料を配る。短い筋を本文で引き延ばす方式にしない。
- 初回の文字数の補助目安を**1話の本文約4,000文字、うち台詞約2,000文字**に更新する。これは確認したM3の長めの第1話を上回る内容量を用意するための暫定値で、10分との換算式や厳密な下限ではない。3話では本文約12,000文字が目安になる。
- M3の比較台本として本文約3,400〜3,500文字・台詞約1,600〜1,800文字の「図書列車」「魔王軍」も残す。これらがユーザーの約7分の作品だと仮定せず、内容量の参照として使う。
- 字数、台詞の絶対量、各話の展開を合わせてレビューする。意味検査の再試行、行の細切れ、長い待機による時間の水増しは追加しない。
- 無音の検証では内容量の比較にとどめる。音声付きで確認する段階では、再生設定を揃えたオート時間も確認する。音声長の合計や無音版の再生時間を、そのまま音声付き1話10分達成の根拠にしない。

新しい作品の生成はまだ行っていない。今回の比較は旧作品と最新作品の現状把握であり、改訂計画によって分量・品質を両立できたという検証結果ではない。
