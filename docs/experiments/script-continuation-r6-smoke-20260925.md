# 題材に依存しない経験・行動の具体化

2026-09-25。`script_continuation_v1` revision 6、prompt 6 / implementation 7 / contract revision 5。

## 変更

- 全3章の核心は初期行動・守る価値観・最後の行動を指定する。転機を核心で独立に生成せず、各出来事の人物行動に `experience` を加える。互換表示用の転機要約はその経験・行動から機械的に導出する。
- 後続章の核心入力から導出済みの転機要約を除く。終わった章の予定が再び事実や未達目標として入らないようにする。元の生成物・表示用要約は保存する。
- 章計画の現在地に `attributed_views` を設け、発言者に帰属する評価・推測を行動・選択から分離する。履歴メモと執筆時の資料解釈にも同じ原則を指示する。
- 場面数の1〜3という目安を外し、独立した結果・判断や場所・時間の変化を区切りにする。一続きの試みと応答を引き延ばさない。容量上限8場面は維持する。
- 相談・和解などの共通手順は要求しない。作品に応じた協力・独立・別離・信念の維持を扱い、非言語の連携も既知の情報や合図から描ける。

話者ID付き台本・演出・Script・Tyrano出力を維持する。意味検査や修復ループ、追加LLM工程はない。参照IDの構造検証のみ既存の有限再試行を使う。3章以外の旧計画経路を保持し、可変章数・長編の設計には踏み込んでいない。通常UIへは未統合の実験経路である。

## 技術確認

関連144テスト成功、対象PythonのRuff成功。従来の3章模擬生成・実際のTyrano出力・再開・コンテキスト調整の確認に加え、独立して出発する、交渉を断って去る、安全基準を維持するという異なる着地で、経験・行動の保存と要約導出を検証した。評価・推測が章計画と執筆入力に分離して保持されることも確認した。

これらはデータの受け渡しと構造の確認であり、LLMが意味を正しく扱うことを保証するテストではない。
