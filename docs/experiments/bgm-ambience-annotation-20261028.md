# BGMと環境音の演出注釈を35章で試す（2026-10-28）

### 場面単位の無音は無くなり、環境音だけの場面も選ばれなかった

- 今の計画で `stop` だった20場面は、すべてBGMのある場面になった（環境音の下敷き5、BGMだけ15）。うち17場面では、その場面の中に止める瞬間が付いた。
- 「祖父の声が届く瞬間」（凪の島 第2章）は、狙いどおり、場面全体の無音から、声が届く行の直前で止めて2行後に戻す形になった。
- 環境音だけの場面は、2回とも0。指示文で「ふつうはBGMを重ねる」「場所や空気の切り替わりは理由にならない」と書いたことが、強く効いたと思われる。嵐の夜の場面（凪の島）のような、環境音だけでも成り立ちそうな場面にも選ばれなかった。

### 聞こえる音は本文に結びついている。ただし、ずれ方に型がある

場面の65%に音が書かれた。作品ごとの差は大きい（境界の迷宮・ステラ・ブリーズ・コンビニは全場面、琥珀色の聖域は2/9、星屑は4/9）。根拠の行を読むと、雨・嵐・市場や駅前の雑踏・教室のざわめき・松明は、本文にその音がはっきり書かれていた。「凪の島」第3章では、雨が弱まって、夜明けの場面で鳥の声に替わる流れまで拾えていた。

ずれは次の4つの型に分かれる。

1. **音ではないもの**: 「風に舞う桜」（モノノケ 第1章の4場面、根拠は花びらが舞う描写）。
2. **一度きりの出来事の音**: 「モノノケの咆哮」「モノノケの絶叫」「馬が走り去る蹄の音」。環境音ではなく効果音に当たる。
3. **消えていく音を根拠にする**: 「喧騒が波のように引き」「賑やかな商店街の喧騒が次第に遠のき」の行を根拠に、雑踏を選んだ。
4. **照らし合わせが甘い**: コンビニのコピー機の待機音 → `machinery`（機関室の低い唸り）、監視塔の強い風 → `storm`（風雨と雷）、城内の混乱した兵士の騒ぎ → `crowd_street`（街の雑踏）。候補が近いものしか無い時に、「合う素材なし」と言わずに選んでいる。

### 合う素材が無かった音（26場面）

風（隙間風・夜風・湿った風・強い風、7場面）、行軍や戦場の喧騒（6）、作中で流れる音楽（ステラ・ブリーズの「異星音楽」、3）、遠くの電車（2）、激しい波（1）など。上の型1・2に当たるもの（桜、怪物の咆哮）も含む。ライブラリに足すなら、風・戦場・電車が候補になる。

### BGMを止める瞬間は多すぎる

章あたり平均2.5件、全章で1件以上。止めている長さは1〜2行が半分強で、すぐに戻す。10分ほどの章で何度も「止める・戻す」を繰り返すことになる。

読んだ印象では、大きく3つに分かれる。

- **効いていそうなもの**: 祖父の声が届く瞬間、友人の飛び降りの告白、「またね」の別れ、「完敗だ」、本文に「世界から音が消えた」「騒音がピタリと止み」と書かれた所。本文が静けさを書いている所は、特に自然。
- **あってもよいが、無くても困らないもの**: 決意の一言、気付きの瞬間。
- **多すぎる原因になっているもの**: 「……っ！」「……あら」「……。」のような短い反応や、日常ものの小さなギャグの間（「明日死ぬね」「美味しい！」）。1行止めてすぐ戻すものが多い。

ほかに気づいたこと。

- 効果音が前提の理由がある: 「鞭で打つという暴力的な衝撃音を際立たせる」「扉が閉まる物理的な音を強調」。効果音はまだ無いので、ここでは本当の無音か環境音だけになる。
- 2回の実行で同じ瞬間を選ぶ（87件中65件）。モデルの基準がぶれているのではなく、基準そのものが低い。指示文を変えれば、変えた分だけ素直に効くはず。

## 分かったこと

- 回答の形で、場面単位の無音を確実に無くせた。今の `stop` がしていた「区切り」の役目は、新しい曲への切り替えに置き換わった。
- 聞こえる音の判断は安定していて、本文に結びついている。ずれには型がある（音ではないもの、一度きりの音、消えていく音、近い素材への妥協）。
- BGMを止める瞬間は、上限を書かないと章に2〜3件付く。上限の数字が目安になる心配とは逆に、上限が無くても「何か選ぼう」とする傾向が出た。
- 環境音だけの場面は、今の指示文では選ばれない。

### BGMを止める瞬間は、ほぼ転換点に絞れた

- 87件から32件に減った。種類は `revelation` 21、`decisive_choice` 10、`loss` 1。`silence_in_text` は0（「世界から音が消えた」は `revelation` として選ばれた）。

- 0件の5章（ひだまり1年1組 第1・4章、放課後の陽だまり時間 第2・3章、鉄と血の叙事詩 第6章）は、2回の実行で同じだった。日常ものの章と、戦いが終わった後の章。

## 3回目: 止めないのがふつう、人の群れは騒がしい時だけ（v3）

- **BGMを止める瞬間**: 「ほとんどの瞬間は音楽が流れ続け、多くの章では止める瞬間が無い。空のリストが期待される答え」と冒頭に置いた。止めるのは、音楽が流れているとおかしい瞬間だけ。種類を `silence_in_text`（本文が静けさを書いている）、`loss`（死や永遠の別れ）、`premise_overturned`（物語の前提が覆る真実）の3つにした。v2 の `decisive_choice` と広い `revelation` は外した。強い感情・決断・驚き・反応・ギャグは「音楽が支える」と明記した。v2 の「章全体を比べてから選ぶ」は、各章で1つ選ぶ方向に働いた疑いがあるので外した。

## 4回目: 環境音を章全体の区間にする（v4）

v3 では、同じ場所が続く場面の間で環境音が途切れる・1場面だけ鳴ることがあった（場面ごとに判断しているため）。ユーザーと相談し、環境音を BGM と同じく場面をまたいで続くものにした。ユーザーの指摘で、「地の文で触れた行から突然鳴り出す」ことも避ける。コード: `scripts/story/probe_music_ambience_spans.py`（v1〜v3 のスクリプトはそのまま残した）。出力: `outputs/music-ambience-v4-20261028/`。

- **区間**: 音の種類・役割・根拠は v3 と同じ基準。始まりは `scene_start`（場面の最初からあった音。本文が後から触れても場面の頭から鳴る。「言及は始まりではない」と明記）か、本文が始まりを書いている行。終わりは、本文が止んだ・遠のいたと書いている行か、`location_change`（場所が変わるまで）か、`chapter_end`。同時に鳴るのは1つだけで、新しい区間が始まると前の区間はそこで終わる。
- **照らし合わせ**: 全素材を候補に並べる（v3 では出どころの種類で絞ったため、雨を「水」に分類すると雨の素材に届かなかった）。
- **BGM**: 「環境音だけ」は、素材のある環境音が場面の最初から最後まで鳴る場面だけ選べる。止める瞬間は v3 のまま。

### 場所が続く場面での途切れは減った

同じ場所が続く場面の間で鳴る音が変わったのは、a で1か所（ステラ・ブリーズ 第3章、市場の歓声が s1 で終わる）。b は4か所で、うち3か所は「ひだまり1年1組」第1章の教室のざわめきが場面ごとに付いたり消えたりしたもの。

「凪の島」第3章は、弱まる雨 → 鳥の声（次の場面まで途切れずに続く）→ 船のエンジン音と、本文どおりに切り替わった。

### 途中から始まる区間は、多くが本文の始まりの行

途中から始まる45区間（場面の最初の行の25を除く）の多くは、本文が始まりを書いている行だった。「巡視艇のエンジンが軽快な駆動音を上げ」「窓の外では小雨が降り始め」「現実の雨音が部屋に流れ込む」「地響きのような足音と共に突撃を開始した」「駅前の賑やかな喧騒が再び聞こえ始め」など。

触れた行から始めてしまったものも少し残る。「琥珀色の聖域」第3章の遠くの部活の声（外の音に一度触れる行から鳴る）など。

### 副作用: 一度きりの音が戻ってきた

区間は「ある行から始まる」と書けるため、一度きりの出来事の音まで区間として付いた。v3 ではほぼ外れていたもの。

- モノノケの咆哮・絶叫・唸り声（7区間）、生徒たちの悲鳴、ショートする電子デバイス、自動ドアの開閉音、遠くのチャイム。
- 物音: 紙をめくる音、万年筆の筆記音、ペンの走る音、スマホの操作音（琥珀色の聖域 第1章だけで4区間）。

多くは合う素材が無く鳴らない。ただ、電子レンジの作動音と電子デバイスの駆動音は `machinery`（機関室の低い唸り）に照らし合わされて鳴る。

### 鳴る量は増えた

鳴る場面は 23% から 42% に増えた。理由は2つ。

- 全素材を候補にしたことで、雨が正しく照らし合わされるようになった（雨・嵐の場面が 11 から 18 に）。これは直したかった取りこぼしで、増えて正しい。
- 人の群れの音（街の雑踏・教室のざわめき・店内の話し声、延べ24場面）と、機械の唸り（7場面）が増えた。

### BGMを止める瞬間

基準は v3 と同じで、11件（b は8件）。本文が静けさを書いている所（「世界から音が消えた」「騒音がピタリと止み」、祖父の声）、前提が覆る真実（「物理的に死ぬことじゃなかったんだ」）、仲間が倒れる瞬間など。v3 より少し増え、「……抹茶、パフェ……。」を本文の静けさとして選んだような、やや弱いものも混じる。

## 5回目: 一度きりの音と人の群れを鳴らさない（v5）

v4 で一度きりの音が区間として戻り、実害が出た（電子レンジの作動音が機関室の唸りとして鳴る等）。人の群れの音は、本文に忠実に判断しても会話の声とぶつかるため、ユーザーと相談して自動では付けないことにした。v4 から次の3つを変えた（`probe_music_ambience_spans.py --criteria v5`）。出力: `outputs/music-ambience-v5-20261028/`。

- **一度きりの音の受け皿**: 区間ごとに、始まりの位置より先に `duration`（`throughout` ずっと続く／`moment` その瞬間）を選ばせる。`moment` は記録に残すが鳴らさない。
- **人の群れ**: 区間としては書かせるが、鳴らさない。
- **照らし合わせ**: 選んだ素材が `same`（同じ音）・`similar`（同じ種類だが別の音や強さ）・`different` のどれかを答えさせ、`same` だけ鳴らす。
- 鳴らさない区間は、ほかの区間を打ち切らない。

### 一度きりの音は鳴らなくなった

`moment` に分けられた68区間は、多くが一度きりの音だった。モノノケの咆哮・絶叫・打撃音、障壁の破砕音、電子レンジの作動音と完了音、自動ドア、チャイム、車のクラクション、スマホの操作音など。受け皿を用意すると、区間の数は増えた（93 → 118）が、増えた分は `moment` に入っている。

ただし、続く音を `moment` に分けたものもある。巡視艇のエンジン駆動音、船のエンジン音、時計の秒針の音、「激しい雨音（中）」など。

### 鳴る音は4区間だけになった

鳴ったのは、凪の島の嵐（第1・2章）と弱まる雨（第3章）、明日の自分からの降り出した小雨（第1章）だけ。どれも本文どおり。

減りすぎた主な原因は、素材の強さの種類が足りないこと。`similar` で鳴らさなかった10区間のうち、境界の迷宮の雨5区間は「規則的な雨音（中）」「雨音、中」などで、`rain_light`（しとしと降る雨）とは強さが違うと答えた。ほかに、冷たい強風 → `storm`、松明 → `campfire`、巡視艇の穏やかな駆動音 → `machinery`、激しい波 → `storm`。モデルが強さの違いを正直に答えた結果で、照らし合わせとしては正しい。

`similar` を鳴らしたと仮定すると、鳴る場面は19（16%）になる。強さ別の雨（弱・中・強）と風（弱・強）、松明や暖炉の火、穏やかな機械の唸りを素材に足せば、この程度に届く見込み。

合う素材が無かったもの（17区間）は、風（隙間風・夜風・湿った風など7区間）、電車の走行音、無線のノイズ、怪異の耳鳴り、作中の音楽、霧、ページをめくる音など。

### 一貫性と安定性

同じ場所が続く場面の間で鳴る音が変わるのは、2回とも0になった。2回の実行は、行ごとの音が1行を除いて一致した。BGMを止める瞬間は8件ずつで、v3・v4 と同じ傾向（本文が静けさを書いている所、前提が覆る真実、仲間が倒れる瞬間）。

## 6回目: 続く音の問い方を変える（v6、13章×1回）

v5 では、霧雨・雨・風・エンジン・時計の秒針など、続く音を `moment` に分けたものがあった。多くは本文がその瞬間の出来事として書いた行（「霧雨が激しさを増し」「エンジン回転数が上がり」）が根拠で、モデルは `moment` を「本文がある瞬間に触れた音」と読んだと思われる。終わりは「場所が変わるまで」や十数行先と答えていて、自己矛盾している（v5 全35章で28件・23件）。

v6 では問い方だけを変えた（`--criteria v6`）。`keeps_sounding`（始まったら誰も何もしなくても鳴り続ける。本文がまれにしか触れなくてもよい）か、`ends_with_its_action`（それを起こす動作や出来事が続く間だけ鳴る）か。ほかは v5 と同じ。取り違えのあった章と、一度きりの音を外せていた章の13章で、1回だけ実行した（v5 の2回の実行がほぼ完全に一致したため）。出力: `outputs/music-ambience-v6-20261028/`。

- **天候は直った**: 霧雨（鉄と血 第2章。鳴るようになった）、雨と湿った風・雨上がりの風・夜風・空虚な風（第5・6章）、現実世界の激しい雨音（境界の迷宮 第2章）、凪の島の雨と風。どれも「鳴り続ける」側になった。時計の秒針も直った。
- **エンジンは直らない**: 巡視艇のエンジン（1行）、船のエンジン（2区間）は、まだ「動作と一緒に終わる」。エンジンは誰かの操作で始まるため、操作に結びついた音と読まれたと思われる。
- **一度きりの音は、ほぼ外れたまま**: 電子レンジの作動音と「チン」、万年筆の書く音（5区間）、モノノケの呻き・絶叫、兵たちの怒号や歓声、不協和音。
- **逆向きの取り違えが2つ出た**: 「モノノケの咆哮」（56行）と「透き通るような旋律」（20行）を「鳴り続ける」にした。どちらも合う素材が無く、鳴ってはいない。

天候の取り違えは問い方で直ったが、エンジンは残り、出来事の音を続く音にする逆向きの取り違えが少し出た。残ったものは、素材の有無で鳴るかどうかが決まる（咆哮や旋律の素材は入れない）。

## 次に考えること

- 止める瞬間の基準を上げる。たとえば、短い反応やギャグの間を対象から外す、章の中で一番強い瞬間から比べて選ばせる、止める長さ（すぐ戻すか）を基準に入れる、など。
- 聞こえる音の基準に、型1〜3を防ぐ書き方を入れる（一度きりの音は対象外、根拠の行でその音が鳴り続けていること）。どれも作品を問わない一般的な基準として書く。
- 照らし合わせで「合う素材なし」を選びやすくする。たとえば、候補ごとに合う・合わないを答えさせる。
- 環境音だけの場面を、選ばれなくてよいとするか、選ばれる余地を残すか。
- ライブラリに足す音（風、戦場、電車）。
