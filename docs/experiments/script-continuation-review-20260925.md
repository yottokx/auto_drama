# 台本継続PoC「閉館前の余白」3章レビュー

対象：outputs/script-relationship-seed1-smoke-20260925/。ポリシーは script_continuation_v1、seed 1。承認済み3章構成の第1章を小規模確認後、同一実験を再開して第3章まで完遂した。Gemma、16k、reasoningなし。以下は保存済み台本を読んだレビューであり、生成中の自動意味検査の合格ではない。コード・台本・実験ログは変更していない。

## 判定

今回の出力では、当初の「各章が同じ導入に戻る」問題は見られず、前章の結果から次章の行動が変わっている。台本形式・演出・Script・Tyrano出力を残して完遂できた点も、本実験の目的に合う。

一方、葵の変化を説明する際に過去の立場を逆にしており、結末の説得力を損なっている。場面単位での執筆範囲にも問題があり、先の場面で閉館まで描いた後、残る場面を予定外の別れの描写で埋めている。現方式を次の改善の基準にできるが、作品として十分な品質、別題材でも同様に成功することまでは確認できていない。

## 章間の流れ

| 章 | 実際に起きること | 次章への影響 |
| --- | --- | --- |
| 1 | 蓮が先に写真を仮配置し、葵が反発。二人が別々に作業する状態になる | 2章で蓮が完成を急かす方法を変え、葵の資料整理を手伝う |
| 2 | 葵が資料を渡し、二人で写真を読む。名前の断定より、来場者への問いを置く方針を決める | 章末で葵が再配置を依頼し、3章がその作業を実行する |
| 3 | 写真の間隔と順番を調整し、問いを書いた札を添え、展示を完成させる | 中心課題に決着がつく |

第2章冒頭の緊張は未解決の対立の継続であり、既に和解した人物が再び同じ対立へ戻るものではない。第2章の資料を渡すやり取りは、信頼の変化を行動で示せている。第2章末の「もう一度、一緒に配置を考え直して」（story.md:221）が第3章の具体的な作業に接続している。

## 優先して改善する点

### 1. 葵の変化を誤って説明している

第1章の葵は「急いで間違ったものを出すくらいなら、空白のままの方が誠実」（story.md:47）と発言する。しかし第3章では、以前は「空白のまま出すくらいなら未完成の方がまし」と考えていたと描かれる（251）。結末でも蓮は「空白でいい」という発言に驚いたと語る（295）。

実際に描かれた変化は、空白を認められない人物が認めるようになることではなく、自分だけで確定しようとしていた情報を、来場者への問いとして公開し、他者の参加に委ねられるようになること。この違いが人物の成長と結末の意味を左右する。単なる小物の不一致より優先度が高い。

第3章第1場面の入力には第1・第2章の実台本が全文入っている。この誤記をコンテキスト圧縮による原文欠落のせいにはできない。構成案・引き継ぎメモが「正解への固執からの解放」と変化を一般化している点は、入力側で改善できる候補だが、それが単独の原因と断定はしない。

### 2. 前の場面が後の場面の役割まで描き切る

第3章計画では、第1場面は展示作業の完了、第2場面は完成の確認と消灯・退出を担当する。しかし第1場面の実台本が二十時・展示完成・消灯まで進む（story.md:267–283）。続く第2場面は実台本に合わせて廊下・玄関・帰宅へ進んでいるため、大きな時間の巻き戻しは回避したものの、同じ結論をもう一度説明している。

現在の執筆依頼には当場面の計画と全体構成が入り、後続場面が担当する範囲は明示されていない。当場面の終了点と、次の場面に残す行動を併せて伝えることを優先したい。実際に先へ進んだ場合は未執筆場面の重複を調整し、既出の結末を再び説明させない。

この逸脱は背景要求にも影響する。第3章第2場面の台本は廊下・玄関・屋外へ移動するが、場面定義とScriptの背景は展示室のままである。固定テスト画像を実画像に差し替えるだけでは、本文の場所に合う背景切り替えにならない。これは未知IDや参照切れとしては検出されない。

### 3. 変化を説明する台詞と地の文が多い

第1章の二つの場面は、どちらも「仮置きへの反発→正確さと完成の議論→沈黙」で終わり、章内には反復が残る。第2章では資料を渡すまでの慎重さは良いが、その後は看板の発見から名前不一致の仮説、赤い袋の意味、新しい展示方針へと円滑に進みすぎる。

「表面的な正解に過ぎない」（story.md:203）など、人物が作品の主題を解説する台詞が多い。具体的な札を一度作って並べ、相手がどう反応するかを通して判断を変える余地がある。第3章冒頭の「一章で衝突した」（225）も、構成資料の表現が台本へ漏れた箇所である。

## 次の判断

今回の主目的である章の継続と完遂については、実例が得られた。次は当場面と後続場面の役割を明示し、人物の変化を実際の選択・行動に結び付ける改善を優先する。細かな意味検査の大量復活やQwenの常時導入を、この結果から必須とする根拠はない。
