最初に、設計案どおり発話IDをキーにした object（行ごとに欄の定義を持つ形）で送った。Gemma と GPT-6 Luna は11まとまりすべて通ったが、Haiku は全部「文法が大きすぎる」（HTTP 400）で失敗した。

### 来た・去った

- 3モデルとも、ふつうの話者の顔に serious を多く使った（張り詰めた戦記の章なので、本文に合っている）。今の指示文の Gemma は neutral が多かった。

- 英語の混入は0になった（今の指示文では、この章の67/98行が英語）。

## 分かったこと

- 新しい欄と基準は、3モデルとも形の失敗なく使えた。
  - 話者の表情・声・英語の混入はモデル間で安定した。
  - 来た・去ったも、はっきりした手がかりでは一致した。
