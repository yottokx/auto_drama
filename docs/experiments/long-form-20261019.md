# 長尺化の実験: 鉄と血の叙事詩を5章で生成する（2026-10-19）

5章構成にしても、STEP3の内容からSTEP4（キャスト計画・出来事の連鎖・章への配分）とSTEP5（台本）が破綻なく通るかを確かめた。同じ条件の3章版と比べた。

## 条件

- 入力: 鉄と血の叙事詩の承認スナップショット（`outputs/cast-size-20261017/inputs/tetsu-qat-product.json`。登場キャラの上限8、`planned_cast_appears`・`open_scene_cast` あり）。章数だけを5に変えた。
- モデル: gemma-4-31B-it-UD-Q4_K_XL、推論なし、コンテキスト32,768。シードは入力のまま（両方とも同じ）。
- 画像・音声・演出注釈は作らない（`skip_staging`）。
- 実験スクリプト: `scripts/story/check_text_long.py`。製品のコードは変えていない。
- 出力: `outputs/long-form-20261019/tetsu-ud-5ch/`、`outputs/long-form-20261019/tetsu-ud-3ch/`（それぞれ `story.html` で読める）。

### 5章にするために差し替えたもの（このプロセスの中だけ）

製品は3章のときだけ「キャスト計画 → 出来事の連鎖 → 章への配分」の流れに入る。スクリプトは次を章数Nに合わせる。

- 連鎖: 出来事の数を3〜9個から N〜3N個（5章なら5〜15個）にし、説明と指示文の「3章」をNにした（「全N章の分量」「N章の各区間で」）。
- 配分: 章の数をNに、配分の指示文の「全3章へ配分」「均等に三分割」をNにした。出来事がN個ちょうどなら、製品の3章と同じく配分をコードで確定し、題名・役割・会話材料だけを答えさせる。
- キャスト計画: 3章以外では飛ばす条件を外した（指示文は元から章数を使っている）。
- `--chapters 3` では何も差し替えないので、3章版は製品の流れそのもの。

章の場面計画以降（場面計画・本文・聞こえる声の判定・履歴メモ）は元から章数に従うので、手を入れていない。

## 結果

両方とも最後まで完走した。失敗も手戻りも無い（再試行は聞こえる声の判定で数回あり、どちらの版にもある）。

| | 3章 | 5章 |
|---|---|---|
| サブ | 4人（カイル、傭兵団長バルガス、技師リリアン、執行官ガラム） | 3人（カイル、技師マルクス、突撃隊長ヴァルガス） |
| 連鎖の出来事・手順 | 6個・11手順 | 5個・10手順 |
| 章ごとの手順 | 4 / 3 / 4 | 2 / 2 / 2 / 2 / 2 |
| 場面数 | 3 / 3 / 5（計11） | 3 / 3 / 2 / 4 / 3（計15） |
| 本文の字数 | 4,968 / 4,451 / 6,099（計15,518） | 4,074 / 4,312 / 4,217 / 5,822 / 4,560（計22,985） |
| 台詞の字数 | 8,042 | 9,816 |
| 依頼数 | 26 | 35 |
| 生成時間（各依頼の合計） | 3章版を1として | 約1.46倍 |

- 5章版は、出来事を最小の5個しか作らず、1章に1つ（手順2つ）ずつ配分された。手順の総数は3章版とほぼ同じなので、章あたりのプロットの量は約半分になった。
- それでも各章の本文は約4,000〜5,800字で、目安の長さにはなった。字数は約1.5倍、生成時間も約1.5倍で、章数（5/3 ≒ 1.67倍）よりやや少ない。

## 内容（本文を読んで）

### 5章版

- 事実の食い違いは見つからなかった。誰が生きているか、エレナの負傷と運ばれ方、マルクスの欺瞞工作と生還、カイルの避難誘導が、章をまたいで一貫している。第5章は第1・2章を履歴メモで受け取ったが、崩れていない。
- 第4章が第5章の出来事を先に済ませた。第4章の場面計画の最後の場面に、アルリックがエレナを救ってゼノスと対峙し、ゼノスが退いて要塞が崩れ、二人が脱出するまでが入った。予定では第5章の「崩落する要塞の最深部でゼノスと一対一の激突」「ゼノスが悟る」にあたる。第4章は4場面・5,822字で最も長い。
- そのため第5章は後日談になった。生存者との合流、エレナが誇りを失った空しさを語りアルリックが受け止める場面、撤退するゼノスの無言の一瞥、新しい地への出発。第5章の計画は「既に達成したことは再演せず」に従って矛盾なく続けたが、ゼノスには台詞が1つも無い。読み物としては締まっている。
- 同じ主題の繰り返しが目立つ。「誇りを捨てろ、泥を啜ってでも生き残れ」が第1〜5章のすべてで語られ、第2章では2回ある。エレナは第3章で撤退に同意した後、第5章でもう一度誇りの喪失に揺れて決意し直す。1章あたりの出来事が少ないぶん、会話が同じ対立をなぞっている。
- 小さな誤り: 第2章で兵の報告「駄目だ！　出力が足りない！」がアルリックの台詞になっている。ヴァルガスは第3章を最後に、言及も無く消える。

### 3章版

- こちらも食い違いは見つからなかった。サブ4人すべてに台詞がある（リリアンは第2章の6行だけ）。
- 第3章で、ゼノスが空の要塞に気づいて自ら追撃に出る場面と、高台から要塞を見下ろして行軍を始める場面で終わる。結末はゼノスとの対決を残した形。
- 主題の繰り返しは5章版より少ない。章ごとに新しい手順（傭兵との取引、偵察で見つけた盲点、山脈の裂け目の撤退路）があり、会話がそれを運んでいる。

### 両方に共通

- キャスト計画の年齢欄に「，19」「，18」（全角の読点）が混ざった。前回の「।45」と同じ種類の誤り。

## 分かったこと

- 5章でも、出来事の連鎖から台本まで、破綻なく最後まで生成できる。32kなら第5章で圧縮が始まるが、内容は崩れなかった。
- ただし、章数を増やしても連鎖の出来事は増えなかった（5〜15個と伝えても最小の5個）。章あたりの出来事が減り、会話が同じ主題を繰り返すことと、場面計画が次の章の出来事を先取りすることが起きた。ハンドオフで予想した「出来事が同じ少なさなら薄い章が増えるだけ」が、長さではなく内容の繰り返しと先取りとして現れた。
- 生成時間は章数にほぼ比例した（3章版の約1.5倍）。

## 未確認のこと

- 1作品・1シードだけ。出来事が5個ちょうどになったのは偶然かもしれない。
- 連鎖の出来事を章数に応じて増やすよう求めたら（例えば「各章に2個以上」）、繰り返しと先取りが減るか。
- 6章以上や、16kでのコンテキスト。
- 演出注釈を入れた場合の生成時間。
