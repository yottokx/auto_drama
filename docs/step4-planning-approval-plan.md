# STEP4の構成確認とSTEP5の章制作への分割計画

作成日：2026-10-01  
状態：計画のみ。アプリの実装変更と生成処理は未実施。

現在のSTEP4を、全体構成を確認するSTEP4と、章を順番に制作するSTEP5に分ける。STEP4で全体プロットと予定サブキャラを確認・修正し、承認後はLLMが必要な人物や場面を補いながら制作する。完成後は実際の背景を使い、人物の表示位置・倍率・立ち絵・声を調整できるようにする。

最初の依頼ではサブキャラ素材の生成と表示調整もSTEP4に含めていたが、その後の相談を踏まえ、本計画では素材生成をSTEP5、素材の差し替えと表示調整を完成後へ移す。予定キャストの承認で登場人物を固定せず、制作中の追加サブキャラを許容する。完成後の素材生成に使う指示は、その1回だけのプロンプトとして扱う。画像・基準音声のアップロードにも対応する。

この計画は、従来の「世界観・メインキャラ承認後は追加承認なしで直ちに本文を制作する」という開始条件を変更する。STEP4承認後の通常制作では、章ごとの追加承認を要求しない。

## 制作の流れ

| 段階 | ユーザーが確認する内容 | 次へ進む条件 |
| --- | --- | --- |
| STEP1 | 世界観とメインキャラへの希望を入力 | 入力を保存して世界観生成へ進む |
| STEP2 | 世界観を確認・修正 | 世界観を確定する |
| STEP3 | メインキャラの設定・関係性・立ち絵・基準音声を確認・修正 | 承認してSTEP4の構成生成を開始する |
| STEP4 | 全体プロットと予定サブキャラの設定・関係性を確認・修正 | 「構成を承認して本編を制作」を実行する |
| STEP5 | 第1章から順番に制作状況を確認し、完成した章を鑑賞する | 全章完成後に同じ画面から事後調整へ進める |
| STEP5内の完成後調整 | 実際の背景で表示位置・倍率を調整し、立ち絵・基準音声を差し替える | 調整版を反映し、鑑賞・書き出しに使用する |

STEP3の承認では本文ジョブを投入しない。共通工程として「予定キャスト設計 → 全体プロット・章への配分」を生成し、STEP4で待機する。STEP4承認と第1章の制作開始を一つの処理として記録する。

STEP5は第N章の章計画・本文・演出・素材・組み立て・公開が完了してから第N+1章へ進む。現在の本文採用直後に次章本文を先行生成する処理は、新方式では章の公開完了を待つ形に変える。完成した章の鑑賞、停止・中断・再開、失敗工程の再試行を引き続き使えるようにする。

## STEP4で確認と修正を行う範囲

全体プロットには各章の概要と役割、主要な出来事、結末、人物の変化、伏線、章に配分した会話材料を表示する。内部の計画に存在する内容をユーザーが確認できる形で表示し、表示用の要約だけを修正して実際の生成入力に反映されない状態を作らない。

予定サブキャラは名前・役割・基本設定・外見と声の方針・生活上の関心・初期知識・他の人物との関係を確認できるようにする。立ち絵・基準音声はこの段階の承認条件に含めず、実際の登場時にSTEP5で生成する。メインキャラの既存素材はSTEP3の承認版を参照する。

プロット全体、特定の章、特定のサブキャラ、人物関係を対象に、直接編集とAIへの修正指示を提供する。ユーザーが指示した対象と、その変更に必要な関連部分を更新し、変更箇所と以前の版を確認できるようにする。個々の修正結果を反映するたびに別の承認画面を挟まず、最終的にSTEP4全体を承認する。

| 編集内容 | 更新するもの |
| --- | --- |
| プロットや章の内容 | 正本の計画とそこから作る章配分・表示用データ |
| サブキャラの性格・役割・関係性 | 人物定義と関係資料。影響するプロットも修正対象として明示し、必要な修正を反映する |
| 外見・声の方針 | STEP5で素材生成に使う人物設定。物語上の意味にも関わる変更だけ、関連するプロットを見直す |
| サブキャラの追加・削除 | キャスト一覧、関係、プロット中の人物参照。削除した人物の参照を残さない |
| 世界観・メインキャラの基本設定 | STEP2・3へ戻って変更し、新しい承認版に基づくSTEP4を作る |

AI修正の入力には現在の計画版、対象、ユーザー指示、承認済みの世界観・メイン設定を含める。修正結果の人物ID・章数・参照を検証し、成功した結果を新しい下書き版として採用する。失敗・中断時には修正前の有効な下書きを保持する。プロットとキャストの変更履歴を保存し、未保存の入力や古い版を元にした応答が新しい内容を上書きしないようにする。

現在の先行キャスト設計は全3章の場合だけ動くため、この分割と併せて既存の対応章数全体へ適用する。章数に応じた全体プロットの分割生成は利用しつつ、どの章数でも「キャスト計画と全体プロットを確認してから第1章へ進む」流れに統一する。

## LLMが制作中に決められること

STEP4の承認対象は制作の出発点となる全体構成と予定キャストとする。STEP5ではその方向性とユーザーが明示した制約を守り、各場面の会話・行動・演出を具体化し、必要なサブキャラを追加できるようにする。予定サブキャラ全員の出演や、毎章の新規人物追加は義務にしない。

追加サブキャラは既存の章計画の仕組みを使い、安定した人物IDと基本設定を保存して後続章へ引き継ぐ。その人物の立ち絵・基準音声も初登場時に生成する。ユーザーが「登場人物はこの人数だけ」などと指定している場合は、その制約を優先する。

STEP4で承認した資料は承認記録として保持する。予定していた人物と制作中に追加した人物は、完成後の一覧で由来を確認できるようにする。過去の出来事や人物の知識は実際の台本から引き継ぎ、未来の予定を実績として扱わない。

通常の人物追加は承認待ちで止めない。自動で全体の結末やユーザーの固定条件を別物へ変更する工程は追加せず、承認した構成を章内で具体化する範囲で自律性を保つ。

## 完成後の表示調整

STEP5に「表示と素材を調整」を設ける。初期実装では全章の完成後に編集を有効にし、制作中に同じ素材を参照するジョブと競合しないようにする。制作中も完成済みの章は鑑賞できる。

ユーザーは章と場面を選び、その場面の実際の背景をプレビューする。メイン・サブを合わせた全登場人物一覧からチェックした人物を表示し、ダミーの名前と台詞を入れたメッセージウインドウを重ねる。場面に元から登場する人物を初期選択するが、比較のため別の人物も選べる。プレビューの人物選択は本編の出演者を書き換えない。

現行VNは960×640の3:2である。ステージ寸法、背景の収め方、メッセージウインドウの位置・大きさ・重なり順、立ち絵の配置値を出力側と共通化する。ブラウザーの幅に合わせて画面全体を等比縮小し、見た目だけ似せた別の配置計算を作らない。

| 操作 | 仕様 |
| --- | --- |
| キャラの表示選択 | メイン・サブ両方から選ぶ。同時表示は現行VNと同じ最大3人。作品全体の人物数制限とは分ける |
| 左・中央・右の切替 | 各位置で見え方を確認するプレビュー操作。本編の場面演出は変更しない |
| 表示高さ | 画面上の上下位置をスライダーと数値で調整する。設定上の身長とは別の値 |
| 倍率 | 縦横比を維持して拡大・縮小する。スライダーと数値で調整する |
| 初期値に戻す | 人物ごとに、自動配置に戻せる |
| 人物範囲の詳細補正 | 現在の人物範囲を囲む調整を詳細設定として再利用する |

人物ごとの表示高さ・倍率は作品の調整版に保存し、その人物が登場する全章へ適用する。選択した背景は確認用であり、本編の背景割り当てを変えない。場面ごとの個別表示補正は初期実装の必須機能に含めない。

現在の配置計算は、その章の人物の身長や画像幅から共通倍率を求めるため、組み合わせによって同じ人物の大きさが変わり得る。新方式では作品の基準座標・自動配置の基準を固定し、人物ごとに算出した配置を保存する。後からサブキャラが増えたときは、その人物の配置だけを追加する。プレビューのチェック状態や各章の人物集合で、既存人物の倍率を再計算しない。

立ち絵を差し替えた場合は、新しい画像に対する人物範囲と基準配置を再計算する。旧画像の補正範囲を無条件に引き継がず、同じプレビューで確認して反映する。

## 立ち絵と基準音声の差し替え

完成後の素材調整は、STEP4の人物設定の修正と別の操作にする。名前・性格・外見設定・声の設定・人物関係・承認済みプロット・本文を変更せず、作品で使用する素材の版を変更する。

差し替え方法は、今回だけのプロンプトによる生成、手元のファイルのアップロード、保存済み素材への切り替えを用意する。生成・アップロードした候補をプレビューまたは試聴してから、調整中の版に選択する。元の素材は残し、戻せるようにする。

ワンタイムの指示はその生成ジョブだけへ渡す。必要なキャラ設定は生成の参考として読み取るが、指示や生成結果を人物設定や累積の修正指示へ書き戻さない。プロンプトを履歴・生成元の記録として保存しても、次のリテイクへ自動加算しない。同じジョブの再試行では同じ指示を使い、新しい生成操作ではユーザーが今回入力した指示だけを使う。

| 対象 | アップロードと確認 | 反映時の処理 |
| --- | --- | --- |
| 立ち絵 | PNG・WebP・JPEGを読み込み、表示用形式に正規化する。透過画像は透過を保持する。非透過画像は背景が残る状態もプレビューできるようにする | 新画像の配置を確認し、その人物が登場する章を再組み立てする |
| 基準音声 | 音声を試聴し、含まれる読み上げ文をユーザーが入力・確認する。クローン用に音声と対応文を一組で保存する | その人物の生成済み台詞音声を新しい基準音声から作り直し、該当章を再組み立てする |

音声はWAVを基本対応とし、MP3も取り込める構成にする。音声を実際にデコードして既存TTSが受け取れるWAVへ正規化する。実装の最初に利用可能なデコーダーを確認し、必要な依存をワーカー環境へ明示的に追加する。取り込み可能な形式・容量・長さの上限を画面とAPIで一致させる。

アップロード原本と正規化後の素材を分けて保存し、ファイル内容・サイズ・画像寸法または音声の長さを検証する。クライアントのファイル名を保存先パスとして使わず、保存された素材IDで扱う。これらはファイル取り込みの技術的な検証とし、追加の人物設定承認にはしない。

新しい基準音声の候補では、既存台詞の短い試聴を作って声を確認できるようにする。反映時には発話の文字列・話者ID・感情指定を保持し、音声だけを再生成する。人物設定や台本の再生成を伴わせない。

## 保存する版と承認の境界

| 記録 | 保存する内容 |
| --- | --- |
| STEP3承認版 | 既存の世界観・メインキャラ・関係性・メイン素材 |
| STEP4下書き | 元のSTEP3承認ID、予定キャスト、プロット、章配分、ユーザー指示、版番号、生成状態 |
| STEP4承認版 | 承認した下書きの固定スナップショット、ハッシュ、作成元と生成方式 |
| STEP5制作系列 | STEP3・STEP4承認への参照、各章の本文、実際に追加した人物と素材、章間の引き継ぎ記録 |
| 完成後の調整版 | 人物別の選択素材・音声の対応文・表示補正、元の公開版、章ごとの更新ビルドの対応表 |

STEP4で承認済みの下書きを再編集するときは、新しい下書き版を作る。変更後の構成を承認して本編を作り直す場合は新しい制作系列として第1章から開始し、既存の完成作品は残す。完成後の素材調整は同じ本文に対する別の表示・音声版として扱う。

STEP4承認時は、最新の下書き版とSTEP3承認の対応、構成の生成・修正完了、人物・章の参照、未保存変更がないことを確認する。承認処理を重ねて送信しても、第1章の制作を二重に作らない。

編集・生成・承認・履歴復元は版番号を照合する。古い版を元にしたジョブの完了通知は記録を保持しつつ、新しい選択版へ採用しない。再開・再試行や直接APIを呼ぶ経路もSTEP4承認の有無を確認し、画面のボタン無効化だけに依存しない。

## STEP5への受け渡しと調整版の公開

STEP4の共通工程を第1章本文から独立したジョブに切り出す。第1章は明示的な承認済み計画入力を受け取り、キャスト計画やプロットを再生成せず章計画から始める。現在の章間チェックポイントは第1章の前章継承を拒否するため、計画を架空の第0章として渡さず、承認済み計画用の入力を追加する。

計画承認のID・ハッシュ・生成方式は、制作系列、章ジョブ、チェックポイントに含める。STEP4の正本が複数の内部形式から成る場合も、プロットだけを差し替えて出来事の連鎖や章配分が古いまま残らないよう、整合する一式を確定して渡す。STEP4の生成・修正に使った時間と使用量は、第1章本文の生成履歴とは識別できる形で記録する。

初登場サブキャラの立ち絵・基準音声は既存の素材生成経路を利用し、同じ人物の素材を後続章でも再利用する。追加人物のID・素材・人物設定を章間で維持する。

完成後の調整は、変更の種類に応じた処理だけを実行する。

| 調整 | 必要な処理 |
| --- | --- |
| 表示高さ・倍率・人物範囲 | 保存済み本文と素材から、該当章のScript・表示ファイルを再組み立てする |
| 立ち絵 | 生成またはアップロードした候補と表示補正を使い、該当章を再組み立てする |
| 基準音声 | 該当人物の全台詞音声を生成し直し、その人物が話す章を再組み立てする |

調整版は、影響する全章の素材とビルドがそろってから一括で選択版へ切り替える。途中失敗では元の公開版を鑑賞でき、成功済みの素材を使って失敗工程だけを再試行できる。本文の原文・発話ID・場面構成は調整前後で一致させる。

章ごとの最新ビルドを個別に選ぶだけでは、新旧の素材版が章の途中で混在する。作品の調整版ごとに章ビルドの対応表を保存し、章リンク、次章移動、章別ZIP、まとめ書き出しが同じ対応表を使うようにする。古い公開URLとその版の閲覧保存は残す。閲覧位置を異なる版へ自動移行する処理は追加しない。

現在のDBは`approval_id`と章番号の組を一意にしている。同じSTEP3承認から異なるSTEP4承認版の作品を作れるよう、制作系列と章番号の組を一意にする構成へ移行し、STEP4承認IDによる開始の重複防止を別に設ける。

現在の立ち絵APIには公開第1章や最大10人を前提とする箇所がある。全章の実登場人物を取得するAPIにし、作品全体の登録人物数、同時表示3人、画面の一覧件数を混同しない。素材調整ジョブは通常の章制作ジョブと区別し、人物設定の修正処理や累積指示保存へ流さない。

## 既存作品の扱い

新方式の識別子を保存し、新規の制作開始から適用する。旧方式で制作済み・制作中の作品は既存の承認・本文・素材・公開版を保持し、移行だけを理由に生成を開始したり、未実施のSTEP4承認があったことにしたりしない。

旧方式の進行中作品は旧方式の再開条件を保つ。新しい構成確認から作り直す場合は、利用できる保存済み設定・計画を新しいSTEP4下書きへ読み込み、承認後に別の制作系列を開始する。旧作品の完成後調整は、既存素材と配置を読み込んで新しい調整版を作る。閲覧しただけでは位置や素材を変更しない。

## 実装順序と確認項目

1. **契約と保存境界を追加する。** 計画下書き・承認・制作系列・調整版のデータ構造、DB移行、履歴とジョブの版確認を先に定める。
2. **計画生成を本文から分離する。** STEP3承認で共通計画だけを生成し、STEP4承認済み入力から第1章を開始できるようにする。3章以外の経路も合わせる。
3. **STEP4の画面とAI修正を接続する。** 5ステップ化、全体プロット・サブキャラの編集、変更履歴、承認ゲートを実装する。
4. **STEP5の章制作を接続する。** 章の完成後に次章へ進め、追加サブキャラと素材を引き継ぐ。停止・再開・再試行を確認する。
5. **完成後の表示プレビューを作る。** 実際の背景、メイン・サブ選択、メッセージウインドウ、上下位置・倍率、共通配置計算を接続する。
6. **素材差し替えを作る。** ワンタイム生成、画像・音声アップロード、候補選択、台詞音声の再生成、全章の調整版の一括反映を実装する。
7. **移行と通し確認を行う。** デモ・使い方・既存作品の履歴を更新し、実際の生成・試聴・VN再生で確認する。

受け入れ確認では、次を重視する。

- STEP3承認後に共通計画だけが生成され、STEP4承認前には本文が生成されない。再開・再試行・直接API経由でも同じ条件になる。
- 全体プロット・サブキャラの直接編集とAI修正が、承認された版の実際の執筆入力へ反映される。第1章で承認済み計画を作り直さない。
- 1章、2章、3章、分割計画を使う9章以上で共通工程の分離と承認の受け渡しを確認する。長編の作品品質は形式検証と分けて評価する。
- STEP5の途中で追加した人物のID・設定・立ち絵・基準音声が後続章へ引き継がれ、通常の追加で承認待ちにならない。
- 第N章が公開される前に第N+1章の制作が開始されず、失敗・停止時に同じ章から再開できる。
- 背景とメッセージウインドウを含むプレビューとVN出力で、同じ位置・倍率になる。選択人物・章・後から追加された人物によって、既存人物の表示倍率が変わらない。
- ワンタイムの生成とアップロードの前後で人物設定・承認内容・本文が変わらず、前のリテイク指示が次の生成へ自動継承されない。
- 画像の透過・縦横比と、アップロード音声の対応文が保存され、取り込み失敗でも既存素材を失わない。
- 基準音声の差し替えで該当人物の台詞だけが再生成され、台詞本文と他人物の音声は保たれる。画像差し替えでは本文や音声を再生成しない。
- 調整中に失敗しても旧公開版を鑑賞でき、反映後は全章の鑑賞・次章移動・書き出しが同じ調整版を参照する。履歴復元や古いジョブ応答で新しい版が上書きされない。

既存のウィザード・キャスト・章生成・人物配置・API承認・履歴・書き出しのテストを中心に拡張する。自動テストによる版管理・参照・配置の確認に加え、実モデルで追加人物を含む複数章を生成し、画像差し替えと基準音声差し替えをそれぞれ実際のVNで確認する。計画の作成時点では、これらの実装と検証はまだ行っていない。
