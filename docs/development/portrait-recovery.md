# サブキャラ立ち絵の失敗時復旧

通常のキャラ・物語・画像プロンプト生成には、特殊な表現方法の選択肢や事前判定を追加しない。
本編のサブキャラ立ち絵（`m3_image`）が失敗した場合だけ、元設定、実際の画像プロンプト、失敗工程、ログを使って診断する。

- メモリ不足、タイムアウト、依存関係やファイルの不足などは、プロンプト修正や画像省略へ振り替えない。
- 描画プロンプトの問題と判断した場合は、元設定を保った修正を1回だけ試す。画像処理の原因が不明な場合は停止する。
- 背景透過処理に失敗し、元設定に姿がないことが明示されている場合に限り、設定の正確な引用を伴う `omit_portrait` を返せる。
- 幽霊、透明な体、異形などの属性だけでは省略しない。台詞・話者ID・音声・キャラ設定は変更しない。
- 再生成も失敗した場合、同じジョブの再試行で画像再生成を繰り返さない。診断と再試行の記録を `portrait-recovery/state.json` に保存する。

画像省略は空のPNGや通常の画像成功に偽装しない。画像を含まない専用の結果をコーディネーターで検証し、`portrait_omission` のJSON成果物として保存する。章の公開時に、元設定と引用を再照合する。話者は台本に残し、そのキャラに対する立ち絵の入退場・位置・フォーカス演出だけを出力から除外する。同一設定の後続章は、この省略成果物も既存の素材共有経路で再利用する。

この対応は本編サブキャラ用。承認前のメインキャラ素材生成は従来の契約を維持する。創作プロンプトへの診断結果のフィードバックは行わない。

ワーカーとコーディネーターの両方の再起動が必要。既に失敗しているジョブは再試行から新しい復旧経路に入る。実行中のジョブや既存の生成結果は、このコード変更だけでは更新されない。
