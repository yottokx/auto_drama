# TTSモデルのダウンロードと設定画面

設定画面のLLM／TTSタブから、Irodori-TTS v4.1 Small／v4 Largeのモデル取得と用途別の生成設定を操作できる。保存したTTS設定は、新しく作成する音声生成ジョブへ適用される。

## ダウンロードする

1. CoordinatorとWebを更新後のコードで起動する。
2. 更新後の通常Workerを起動する。モデル取得は既存のWorkerが担当し、専用のWorkerは追加しない。
3. サイドバーの「設定」を開き、「TTS」タブを選ぶ。
4. 保存先、モデル、精度を選び、「ダウンロード」を押す。
5. 進捗と検証の完了を確認する。画面を閉じても取得は続く。

```powershell
.\scripts\start-worker.ps1 -Name local
```

Workerは外部通信が可能な通常のターミナルから起動する。通信制限のある実行環境では、Windowsのソケットエラー10013で取得を開始できない。画面に外部通信の拒否が表示された場合は、通常のターミナルから上記コマンドを実行し、その保存先を選択して再開する。

Small／Largeそれぞれのfp32／bf16／int8／int4を取得できる。fp32とbf16は同じ公式通常ウェイトを共有し、重複して取得しない。int8はint8-weight-only、int4はint4-weight-onlyを使用する。必要なtokenizer、codec、watermarkのウェイトも取得する。

取得元のrevisionとファイルのハッシュを固定し、検証が通ってから取得済みと表示する。用途別設定では、取得・検証が完了し、オンラインのWorkerでランタイムとGPUの条件を満たすモデル・精度だけを選べる。未取得のモデル・精度は「利用不可」と表示され、保存APIでも受け付けない。実際の生成時にも選択したファイルのハッシュを検査する。

## 中断と再開

ダウンロード中は「中断」で停止でき、部分ファイルは保持する。「再開」は同じ固定版を使い、残りを取得する。WorkerやCoordinatorを終了した場合は、leaseの期限切れ後に中断状態となる。Workerを再起動して、新しい接続先Workerを選び、再開する。

同じPC・同じモデル配置先なら部分ファイルを再利用できる。別PCを再開先に選んだ場合、そのPCに保存されたファイルから取得を始める。通信・容量・ハッシュ検査の失敗は画面に表示され、失敗したファイルを完成扱いにしない。

## 用途別の設定

1. 「ボイスデザイン」でモデル・精度を選ぶ。
2. 「ボイスクローン」のモデル・精度も選ぶ。デザインと同じ組み合わせでも、別の組み合わせでも保存できる。
3. 「保存」を押す。Large・bf16を使う場合は、両用途または使用したい用途をその組み合わせにする。

設定保存とモデル取得は独立しており、保存で取得を自動開始しない。通常ウェイトを取得済みならfp32とbf16の両方を選べる。量子化版を取得していなければint8／int4は選択できない。

M2の基準音声・試聴には、ジョブ作成時の用途別設定を使用する。M3／M4の本編には制作開始時の設定を保存し、後続章や素材の再試行も同じ設定を引き継ぐ。既存の音声は設定保存だけで再生成されず、変更する場合はリテイクする。導入前のジョブ・本編は従来のSmall設定で処理する。

モデルや精度を切り替えると常駐音声プロセスを入れ替え、同じ組み合わせでは再利用する。音声ジョブが連続する間は経過時間によるアンロードを行わず、仕事がなくなった時、エラー・キャンセル時、ほかの種類の処理へ移る時に解放する。生成結果には実際のモデル・精度・固定revision・依存・watermarkなどを記録する。

2026-09-30にRTX 5090でLarge・bf16のボイスデザイン／クローン、Largeで作った参照音声を使うSmall・bf16のクローン、Large→Small→Largeの切り替えを確認した。量子化版の実ウェイトはこの検証では取得していない。

LLMタブは既存のLLM共通設定を使う。LLMの保存は引き続き新規ジョブへ適用される。
