# M2：世界観からキャストへ進む設定ウィザード

この文書はM2の実装に先立って作成したUIプロトタイプの記録です。その後、通常ルートには実生成・サーバー保存・承認を接続しました。現在の起動方法・保存範囲は [M2の使い方](m2.md) を参照してください。以下のブラウザー内保存や未接続の説明は当時のプロトタイプに関するものです。表示サンプルは引き続き `?demo=results` で利用できます。

2026-09-22のユーザー指定により、世界観とキャストを一画面でまとめて確認する初案から、世界観・方向性を先に確認して確定し、その後にメインキャラクターを指定する4段階のウィザードへ変更しました。世界観の確定とキャスト確認後の承認を分ける方針です。

2026-09-23に入力順を再変更しました。現在は「世界観とメインキャラを指示 → 世界観を確定 → メインキャラを確定」の3段階です。入力をまとめ、世界観生成が人物の希望を参照できるようにしつつ、生成・確認は世界観から順に進めます。表示サンプルも3段階に合わせています。以下の4段階の記述は旧実装の記録です。

## 起動

リポジトリルートで、次のPowerShellコマンドを実行します。

```powershell
.\scripts\start-web.ps1
```

[M2画面](http://127.0.0.1:5173/)を開きます。外観デモには制御サーバー、ワーカー、GPU、モデルの起動は不要です。既存のM1画面は [M1の実装済み画面](http://127.0.0.1:5173/?view=m1) で引き続き利用できます。M1の実行には [M1の起動手順](m1.md)に従って制御サーバーとワーカーも起動してください。

## 4段階の操作

| 段階 | 指示・確認する内容 |
|---|---|
| 1. 世界観・方向性を指示 | 物語のアイデア、作品名、ジャンル、雰囲気、章数、補足の希望を入力します。ジャンルと雰囲気は候補だけに限定せず、自由入力や組み合わせに対応します。 |
| 2. 世界観を確認・修正・確定 | 世界観の結果を見出し・本文のHTMLで読み、内容に納得したら確定します。修正ボタンからのみ直接編集でき、自然言語の修正欄は結果の下で開閉します。世界観を確定するまでは、キャラクターの段階へ進めません。 |
| 3. メインキャラクターを指示 | 名前・年齢層・性別・役割などの任意項目と、項目に収まらない希望を伝える自由記述欄を用意します。メインキャラクターを複数追加できます。 |
| 4. キャストを確認・修正 | 人物設定・立ち絵・声の結果を先に確認します。直接編集は各欄の修正ボタンで開きます。結果下のアコーディオンでキャラクター全体または特定の部分への自然言語修正を指示でき、素材だけのリテイクも別に指定できます。最後に承認操作を試せます。 |

入力の少なさを理由に進行を止めません。世界観の指示やキャラクターの各項目は空欄でも進められ、未指定部分は将来の生成処理に任せる扱いです。新規状態では特定のジャンル・雰囲気・キャラクター像を埋めず、章数は3章、キャラクターは空欄の1人から始まります。キャラクターは追加・削除できますが、最低1人を維持します。

## 結果を先に読む確認画面

確認画面は完成した生成結果を読む場とし、追加入力を求める「確定したい設定・補足」は廃止しました。結果は通常のHTMLで表示し、修正ボタンを押すまで編集フォームを表示しません。直接編集は保存・キャンセル式で、未保存の変更がある間は確定や画面移動から保護します。自然言語の修正フォームは結果の下にあり、初期状態では閉じています。最初の入力指示は別の開閉欄に置き、結果の本文と区別します。

実生成が未接続のため、本文がない場合は生成待ちの表示になります。空の結果欄をユーザーが埋めることは求めません。完成した結果の外観は [生成結果の表示サンプル](http://127.0.0.1:5173/?demo=results) で確認できます。このサンプルは固定の例文とM0の参考素材を用い、入力に基づくAI生成ではないことを画面上に示します。保存先は `auto-drama:m2-result-sample:v1` で、通常の下書きとは分離しています。作品のジャンルや入力値をサンプルで上書きしません。

## 修正指示と固定

キャストの修正では、次の対象を区別して記録します。

| 修正対象 | 用途 |
|---|---|
| キャラクター全体 | 設定・外見・声を含む人物像全体への変更を指示します。固定中の部分は保護対象として記録します。 |
| 設定 | 人物の背景、性格、関係性などの設定に対して指示します。 |
| 外見 | 髪型、服装、体格など、外見のイメージに対して指示します。 |
| 声 | 声質や話し方など、声のイメージに対して指示します。 |
| 立ち絵のリテイク | 人物像全体の変更とは別に、立ち絵素材を作り直す指示です。 |
| 声のリテイク | 人物像全体の変更とは別に、音声素材を作り直す指示です。 |

設定・外見・声は個別に固定できます。対象が固定されている部分修正は受け付けず、外見を固定すると立ち絵のリテイク、声を固定すると声のリテイクも受け付けません。全体修正では未固定部分を対象とし、すべて固定している場合は修正できません。新規状態ではすべて未固定です。

自然言語の修正指示は、対象・本文・時刻・固定して保護する部分とともに履歴へ保存します。現在のプレビューはAIに接続されていないため、指示を自動解釈して設定や素材へ反映する処理は行いません。既定の候補文に置き換えて修正済みに見せる動作もありません。手動で入力・編集した文章と、今後AIへ渡す修正指示を区別して確認できます。

世界観を編集した場合は、世界観の確定と最終承認が解除されます。キャストの段階で世界観を変更すると世界観の入力へ戻り、世界観への修正指示を保存した場合は確認画面へ戻ります。いずれも既存のキャラクター設定は保持し、世界観を再確定してから続きを確認できます。キャラクターの変更や修正指示の追加でも最終承認を解除します。内容が変わらない保存では版を増やしません。

## 保存範囲と移行

世界観、複数キャラクターの任意入力・固定状態、現在の段階、修正指示履歴、版番号、世界観の確定状態、デモ内の最終承認状態を、そのブラウザーの `localStorage` に保存します。専用キーは `auto-drama:m2-wizard:v1` です。APIキーなどの接続用秘密情報は保存しません。ブラウザーやアクセス先のポートが変わると保存領域は別になります。

新しいキーに保存がない場合は、旧デモの `auto-drama:m2-ui-preview:v1` に保存された入力を移行します。旧保存値にあるタイトル、指示、ジャンル、雰囲気、章数、世界設定、人物設定、声の説明などを保持し、旧形式にない年齢層・性別・自由記述・外見は空欄にします。移行後は世界観の入力から始め、世界観確定と最終承認は解除します。旧キー自体は削除しません。

保存データはschemaを検証し、既知のフィールドだけを読み込みます。新しいキーの保存値が破損している、または未対応形式の場合は空欄の初期状態へ戻ります。ブラウザーの保存が利用できない場合も画面は操作できますが、再読込すると変更内容は失われます。

このデモの承認は、M2で必要となる承認版・素材参照・承認日時のDB記録ではありません。階層的な発案、乱数Toolの実行記録、LLM接続、立ち絵・基準音声の生成、サーバーへの作品保存、本編の自動制作は未実装です。画面上の設定や承認はM1の作品・ジョブ・成果物に影響しません。
