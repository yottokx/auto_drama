# M3：第1章の自動制作・鑑賞・書き出し

承認済みの世界観・メインキャラ・関係性・素材を固定し、全体プロットから第1章の本文、背景、サブキャラ素材、台詞音声までを自動生成します。本文・話者・演出・素材の検査を通った章だけを公開します。制作途中の追加承認はありません。

## 起動と操作

M2と同じ環境・モデルを使います。別々のPowerShellから起動してください。

```powershell
.\scripts\start-coordinator.ps1
.\scripts\start-worker.ps1
.\scripts\start-web.ps1
```

1. [制作画面](http://127.0.0.1:5173/)のSTEP1で世界観とメインキャラを指示し、STEP2で世界観を確定、STEP3でキャストの設定・立ち絵・声・関係性を確認します。
2. 「承認して第1章を制作」を実行すると、承認版の保存と本編ジョブの登録が同時に行われ、STEP4「本編を制作・鑑賞」へ移ります。
3. STEP4で工程の進行を確認し、失敗した工程を再試行できます。ページを閉じても、制御サーバーとワーカーが起動していれば継続します。承認済みで制作をまだ開始していない作品には「承認済みの設定で第1章を制作」が表示され、同じ承認版の制作を重複登録しません。
4. 完成するとSTEP4に「第1章を鑑賞する」「脚本と素材を書き出す」が表示されます。鑑賞ページの開始ボタンから音声付きで再生します。

完成後のSTEP4では「立ち絵の表示を調整」から、人物ごとの本体の基準枠を変更できます。保存すると本文・素材を再利用して新しい公開版を組み立て、鑑賞・書き出しリンクを更新します。

生成履歴と承認の記録は各画面末尾の折りたたみ、本編の工程別履歴はSTEP4の「制作の詳細を表示」にあります。旧キャスト確認画面で保存されていた承認済み・制作済み作品はSTEP4へ引き継ぎます。その後は設定の確認画面へ戻れ、設定を再編集した後もSTEP4から既存の完成章を鑑賞できます。

STEP4の「プロットを確認」を開くと、保存済みのプロットを取得します。全章の題名・役割・要約、結末、人物ごとの変化、伏線を人名付きで確認できます。プロット・本文の検査と採用が終わるまでは待機表示となり、開いたままなら採用後に自動で表示します。プレイヤーにはプロットや未読章の情報を表示しません。

M3は指定章数に沿った全体構成を作り、第1章を完成させます。第2章以降の生成・状態引き継ぎ・次章待機はM4の範囲です。「約10分」へ再生時間を合わせる処理はありません。地の文は表示のみ、人物の台詞を各人の基準音声からクローン生成します。

本編の台詞は個別ジョブのまま、連続生成中のIrodoriモデルだけを再利用します。待機や別の生成処理へ移るときはGPUを解放します。画質・音声の精度・生成ステップ数は変更せず、ジョブの順序変更や複数PCへのモデル別割り当てはM5以降の対応です。切り替え条件と比較用オプションは [M2の起動手順](m2.md#起動) を参照してください。

## ティラノの指定

既定ではプロジェクト直下の `tyranoscript/` にあるインストール済みのV520を読み取り専用で参照します。別の配置を使う場合:

```powershell
.\scripts\start-coordinator.ps1 -TyranoDir 'C:\Games\tyranoscript'
```

`AUTO_DRAMA_TYRANO_DIR` 環境変数でも指定できます。`config/environment.example.toml` は設定例であり、自動では読み込みません。

鑑賞ページは `/player/<build ID>/` です。制御サーバーが公開済みZIP内の作品データと指定したエンジンを組み合わせて配信します。インストール先の原本には書き込みません。エンジンが見つからない場合は鑑賞時に配置エラーを表示します。書き出しにはエンジンを含めません。

鑑賞操作はオート送り、途中保存・復元、既読本文と音声の再生、文字サイズ、音量です。保存領域は採用した脚本ごとに分かれています。

- メッセージウィンドウをクリックするかEnterを押すと、文字表示中は現在の本文を全文表示します。全文表示後にもう一度操作すると、台詞音声の終了を待たずに音声を止めて次へ進みます。場面の演出・待機は完了を待ちます。
- 「バックログ」は文字表示中・音声再生中にも開けます。全文表示が済んだ発話だけが並び、音声付きの台詞を聴き直せます。
- 履歴を開いている間は本編の音声と先への進行を一時停止し、閉じると再開します。オートは停止するため、必要ならもう一度オンにしてください。
- 「途中保存」「続きから」は、本文表示・音声・演出待機が終わってから使えます。復元後の履歴には保存位置より先の本文を表示しません。

立ち絵は透明な余白を除いた輪郭、または指定した本体の基準枠と設定身長から大きさを決めます。人型同士で倍率・足元を共有し、低頭身の人物を個別に拡大せず、背の低い人物の肩まで見えるよう全体を調整します。身長と体の形は初期入力・外見の直接編集で指定でき、人型以外は全身表示を使います。既存作品の設定方法と近似の範囲は末尾の「2026-09-23 身長比による表示」を参照してください。

傘や帽子で人物が小さく見える場合は、STEP4の「立ち絵の表示を調整」を開き、画像上で持ち物を除いた本体の頭頂・足元・左右端を囲んでください。四辺の数値入力や矢印キーによる枠の移動でも調整できます。「自動に戻す」で輪郭による計算に戻り、保存すると調整が鑑賞版へ反映されます。枠は表示の大きさ・中心・足元の基準であり、設定身長を変更したり、画像を切り抜いたりする操作ではありません。枠外の帽子や持ち物は残りますが、画面外にはみ出す場合があります。

基準枠は調整した画像に対応付けて保存します。立ち絵が再生成などで別の画像へ変わった場合は古い枠を適用せず、自動計算へ戻します。

表示コードの更新を完成済みの章へ適用する際は、`POST /api/m3/projects/<作品ID>/rebuild` で本文・素材を再利用して新しい公開版を作れます。旧版は保持され、制作画面の鑑賞・書き出しリンクは最新版になります。2026-09-23の立ち絵配置更新では旧座標のセーブとの混同を避けるため保存領域を分けており、新版は冒頭から始まります。

## 生成・検査・保存

代表台詞・自己紹介は人物の確認と試聴のための資料です。メインキャラ・サブキャラとも、本編の設計・本文生成・内容レビューにはサンプル文を渡さず、設定・口調・発話能力をもとに場面に合う台詞を新しく生成します。サンプル文を第1章へまとめて入れることは要求しません。承認・試聴用の原稿と既存の採用済み本文は保持し、この変更による本文の再生成・修復は行いません。

- サブキャラは必要な人物だけを一度の設定生成で作ります。メインキャラの多段候補探索を適用しません。
- 本文はシーン単位のプレーンテキストで生成・保存します。話者の接頭辞をプログラムで解析し、原文の文字位置・本文・順序を照合して発話IDを発行します。
- 場面の雰囲気、人物の内心、声に出す感情を分けて保持します。絵文字はTTSへの入力時に付与します。
- 重要な出来事ごとに、会話と行動・反応の根拠となる発話IDをレビュー結果へ記録します。欠落、重複、本文の改変、未知の話者・演出参照、未合格のレビューは採用しません。
- メインキャラの承認済み素材を再利用し、背景とサブキャラ素材、発話別の音声を個別の永続ジョブで生成します。
- 原文・構造化結果・採用素材・脚本・manifest・完成ZIPを保存します。検査済みの章buildだけにプレイヤーリンクが付きます。

失敗した工程は制作画面から再試行できます。実行条件と入力の承認版を維持し、完成済み素材を作り直しません。生成・接続の問題は「制作の詳細を表示」から確認します。未読のプロットや題名は鑑賞入口に表示しません。
