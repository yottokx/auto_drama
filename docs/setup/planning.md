# 全体構成の確認と本編制作

2026-10-01。新しい制作ウィザードは5段階です。更新後は制御サーバーとワーカーを再起動し、ブラウザーを再読み込みしてください。

STEP3でメインキャラを承認すると、STEP4で予定サブキャラと全体プロットを生成します。この段階では章本文・サブキャラの立ち絵・基準音声を生成しません。

生成・AI修正中には、サブキャラの設定・関係性、物語の核心・全体プロットなど、LLMが実行している工程を個別に表示します。長い全体プロットが分割生成される場合はその実工程も表示します。通知は有効なジョブ試行のリースと連番に結び付けて保存し、古い試行や旧構成の実行中表示を引き継ぎません。

STEP4は「プロット」「サブキャラ」のタブで切り替えます。通常は文章表示で、結末・人物の変化・各章の出来事と会話材料、予定サブキャラの設定・外見と声の方針・関係性を一覧できます。「直接編集」を押したときだけ、そのタブの編集フォームを表示します。保存すると文章表示へ戻り、取消はそのタブの編集だけを戻します。AIへの修正指示も、ボタンを押して入力欄を開きます。タブを切り替えても未保存の編集は保持します。修正中の結果や未保存の変更がある場合は構成を承認できません。失敗した生成は同じ入力で再試行でき、修正前の内容は保持されます。

「構成を承認して本編を制作」でSTEP5へ進みます。確認したプロットとキャストを第1章の入力として使い、ここで全体計画を再生成しません。第1章の本文・素材・公開が完了してから第2章へ進み、承認した章数まで順番に制作します。

予定キャストは制作の出発点です。ユーザーが指定した条件を守りながら、章計画で必要な追加サブキャラを作る余地を残しています。サブキャラ素材は実際に登場する章で生成し、後続章へ引き継ぎます。

停止・中断・再開・再試行と、完成した章の鑑賞・書き出しは[複数章の制作](m4.md)を参照してください。

既存の制作・本文・素材・公開版は保持します。更新しただけで制作を開始したり、未実施の構成承認があったことにしたりしません。以前の制作は保存済みの方式で継続します。

全章完成後には、実際の背景を使った表示調整、ワンタイムの素材生成、画像・音声のアップロードを利用できます。詳しくは[完成後調整](adjustments.md)を参照してください。
