# 完成後の表示・素材調整

全章の制作が完了すると、STEP5の「完成後調整を開く」から専用画面へ移動できます。制作・鑑賞の画面とは分離され、「制作・鑑賞へ戻る」で戻れます。以前に完成した作品にも対応しています。画面を開いただけでは、公開済みの章やキャラクター設定は変わりません。

「表示位置調整」「立ち絵」「基準音声」では編集対象の人物を選びます。「BGM」では人物とは独立して章と場面を選びます。タブ・人物・場面を切り替えても入力を保持します。未保存の変更や未送信の入力がある場合、作品ライブラリや制作画面への移動を止めます。

## 背景付きプレビューで配置を調整する

章とシーンを選ぶと、そのシーンの背景を使ったプレビューを表示します。VNと同じ960×640の舞台を画面幅に合わせて縮小し、ダミーのメッセージウインドウを重ねています。

メイン・サブを含む全キャラクターから、同時に表示する人物を最大3人までチェックできます。左右・中央の選択はプレビュー用です。台本の登場位置や演出は変更しません。

人物ごとに表示高さと倍率を調整します。数値入力とスライダーのどちらも利用できます。必要に応じて詳細の身体範囲も設定してください。帽子や小物を含めず頭頂から足先までを範囲にすると、身体を基準に配置できます。自動配置へ戻す操作もあります。

表示調整は作品内の同じ人物の全章に適用します。シーンや比較する人物を変えても、確定した基準倍率は変わりません。立ち絵を差し替えた場合は、新しい画像に合わせて身体範囲と配置を確認してください。

## 立ち絵・基準音声を差し替える

次の方法で素材候補を作れます。

- その回だけの指示を入力して生成する。
- 「外見の設定」「声・話し方の設定」を直接編集して生成する。追加指示との併用もできます。
- 手元の画像・音声をアップロードする。
- 保存済みの候補や元の素材を選び直す。

立ち絵・基準音声のタブには、保存済みの「外見の設定」「声・話し方の設定」と編集欄を表示します。元設定へ戻す操作も利用できます。直接編集と追加指示は候補の生成に使用し、承認済みの人物設定には書き戻しません。生成後も編集した設定を画面内に保持し、追加指示は送信後に空に戻します。失敗したジョブの再試行は、同じ入力・指示を使用します。

立ち絵の外見設定は、STEP3と同じ英語変換・検証・共通の全身構図指定を経てAnima用プロンプトにします。衣装や髪型などは外見の設定で編集し、構図・ポーズなどは追加指示で調整できます。候補の「設定と実際の生成指示」で元設定・編集内容・追加指示と、品質指定も含むAnimaに渡した実際のプロンプトを確認できます。基準音声では音声生成に渡した実際の指示を表示します。古い素材に実際の生成指示の記録がない場合でも、保存済みのキャラ設定は表示します。

立ち絵の画像をクリックすると拡大表示できます。「閉じる」または Escape キーで編集へ戻ります。

画像はPNG・WebP・JPEG、縦横それぞれ4096px以内、32MiB以内です。向きを補正してPNGに変換し、透明部分を保持します。背景がある画像は、その背景も表示します。

音声はPCM WAVまたはMP3、0.25〜30秒、32MiB以内です。MP3には制御サーバーのPATH上にあるFFmpegを使用します。利用できない環境ではWAVを選んでください。取り込み時にモノラルの24kHz PCM WAVに変換し、原本も保存します。

基準音声の読み上げ文には、自己紹介台詞を最初から入力しています。必要に応じて編集し、表示されている文章で生成します。空欄では生成・取り込みを実行できません。初期入力のままなら未保存の変更として扱いません。人物・タブの切り替えや生成後も、編集した文章を保持します。アップロード時は、実際に発声している本文に合わせてください。この本文と音声を一組で保持します。候補の基準音声の試聴に加え、既存の台詞を使ったサンプル生成で声を確認できます。

## 場面のBGMを選ぶ

「BGM」タブで章と場面を選ぶと、その場面の元のBGM・生成した候補・取り込んだ候補を表示します。人物の選択は不要です。候補の生成や取り込みだけでは公開版を変更しません。

「120秒のBGM候補を生成」はStable Audio 3.0 Mediumを使い、通常120秒のインストを生成します。英語の音楽プロンプトが空欄なら、作品全体と選択した場面をもとにプロンプトを作成します。楽器や曲調を直接編集し、「今回だけの音楽指示」を追加することもできます。生成後も編集したプロンプトは保持し、送信した追加指示だけを空欄に戻します。候補の「この候補の生成プロンプト」で実際の音楽指示を確認できます。

手元のMP3・WAVも32MiB以内で取り込めます。生成・取り込みの後は、音源からループ区間を自動探索し、MP3の再生用音源と元音源を保存します。探索はCPUで行い、インペインティングは使いません。無音に近い区間が長い場合などは、品質の確認が必要な旨やエラーを表示します。生成や探索に失敗した候補は本編用に選択できません。エラーを確認し、必要なら別の候補を作成してください。

「この候補を試聴」または「冒頭から試聴」を押すと、必ず0秒から再生します。最初は冒頭からBまでを一度再生し、その後はA〜Bを繰り返します。シークバー上のA・Bと青い範囲でループ区間を確認できます。一時停止・再開では現在位置を保持し、シークバーで聴く位置を変更できます。「元の音源を最後まで聴く」を選ぶとループせずに元音源全体を再生します。生成した音源は通常120秒、取り込んだ音源は元の長さで試聴できます。

試聴してから「このBGM候補を選ぶ」で下書きに採用します。「BGMの扱い」では「BGMなし」「前の場面のBGMを続ける」も選べます。継続はその場面へ入った時に前の音源を再スタートせず、そのまま再生する指定です。BGM音量は場面ごとに調整でき、初期値は35%です。台詞の音量とは独立しています。

候補の選択・BGMの扱い・音量を「下書きを保存」で保存し、「調整版を反映」で本編へ適用します。場面を切り替えたり候補の進捗が更新されたりしても、未保存の選択・音量と入力中のプロンプトは保持します。

## BGMの継続範囲と場面転換

通常制作では、章の台詞・地の文・全シーンが確定した後に、全体プロットと前後の出来事を参照してBGMの継続範囲を決めます。台本文面や台本生成の処理は変更しません。同じ曲で支える範囲に複数のシーンを含めることがあり、その範囲全体から新曲のプロンプトを作ります。「前の曲を継続」「無音」の場面では新しい曲を生成しません。自動判断は制作結果として保存し、鑑賞中にLLMを呼び出すことはありません。

「BGM」タブで、自動判断の理由と、現在の指定で同じ曲が続く範囲を確認できます。章冒頭や無音の直後には、継続元がないため「前の場面のBGMを続ける」を指定できません。候補を選ぶか無音を指定してください。継続時の音量は継続元の曲の設定を引き継ぎます。

画面転換は、切り替えなし・ディゾルブ・暗転・即時切り替えから選び、詳細で画面とBGMのフェード時間を指定できます。通常は会話が続く間のBGMを維持し、大きな時間・場所・感情の変化では旧曲のフェードアウト後に新曲をフェードインします。暗転時は画面を覆ってから背景と立ち絵を交換し、次の台詞へ進みます。BGMの先読みは再生中の曲を停止しません。

既存作品の演出を再判断する場合も、保存済みの台本と音源を使います。再判断だけでは新しい音楽・台詞音声・画像を生成しません。下書きの設定を確認し、保存・反映すると新しい公開版になります。手動で新曲を作りたい場合は従来の候補生成を使ってください。

場面転換中は途中状態を保存できません。転換終了後、通常の台詞表示・音声終了後の保存可能な位置で保存できます。旧公開版の保存位置は旧版で利用でき、新しい公開版とは独立します。録画には実際の画面転換とBGMフェードが反映されます。

章末では最後のBGMを継続し、「次の章へ進む」を押すと約0.4秒の暗転とBGMのフェードアウトを同時に始めます。次章へ進めなかった場合は待機画面とBGMを戻します。章末の保存・再開にもBGMの再生位置を含めます。

## 全章への反映と元の版

下書きの保存と公開版への反映は別の操作です。候補や表示位置を確認してから、調整内容を反映します。

立ち絵・表示位置・BGMだけの変更では、台本や台詞音声を再生成しません。基準音声を変更した場合は、その人物が話す全章の台詞音声を再生成します。台詞の文面・話者・感情・シーン順は保持します。

必要な素材と章の組み立てがすべて完了してから、新しい調整版へまとめて切り替えます。生成途中や失敗時も、以前の版を鑑賞できます。失敗した工程だけを再試行し、完成済みの音声を再利用します。

章リンク・次章への移動・章別ZIP・まとめZIPは同じ調整版を参照します。旧URLと旧ZIPは保持します。閲覧位置は公開版ごとに保存するため、別の調整版へ自動的に移しません。「変更履歴・元に戻す」で公開版を選び直せます。

複数の画面から同時に編集した場合、古い下書きからの上書きを拒否します。最新の状態を読み直してから編集してください。

コード更新後は制御サーバーとワーカーを再起動してください。起動時に調整用のDBテーブルを追加し、既存の本文・素材・公開版は保持します。

完成作品の再生処理を更新する場合は、設定を変更せずに「調整版を反映」を実行できます。採用済みの台本・素材・表示設定を保持し、全章を現在のプレイヤーで組み立てた新しい公開版を作ります。
