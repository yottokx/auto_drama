# 完成後の表示・素材調整

全章の制作が完了すると、STEP5の「完成後調整を開く」から専用画面へ移動できます。制作・鑑賞の画面とは分離され、「制作・鑑賞へ戻る」で戻れます。以前に完成した作品にも対応しています。画面を開いただけでは、公開済みの章やキャラクター設定は変わりません。

編集対象の人物を選び、「表示位置調整」「立ち絵」「基準音声」のタブで作業を切り替えます。タブや人物を切り替えても入力を保持します。未保存の変更や未送信の入力がある場合、作品ライブラリや制作画面への移動を止めます。

## 背景付きプレビューで配置を調整する

章とシーンを選ぶと、そのシーンの背景を使ったプレビューを表示します。VNと同じ960×640の舞台を画面幅に合わせて縮小し、ダミーのメッセージウインドウを重ねています。

メイン・サブを含む全キャラクターから、同時に表示する人物を最大3人までチェックできます。左右・中央の選択はプレビュー用です。台本の登場位置や演出は変更しません。

人物ごとに表示高さと倍率を調整します。数値入力とスライダーのどちらも利用できます。必要に応じて詳細の身体範囲も設定してください。帽子や小物を含めず頭頂から足先までを範囲にすると、身体を基準に配置できます。自動配置へ戻す操作もあります。

表示調整は作品内の同じ人物の全章に適用します。シーンや比較する人物を変えても、確定した基準倍率は変わりません。立ち絵を差し替えた場合は、新しい画像に合わせて身体範囲と配置を確認してください。

## 立ち絵・基準音声を差し替える

次の方法で素材候補を作れます。

- その回だけの指示を入力して生成する。
- 「外見の設定」「声・話し方の設定」を直接編集して生成する。追加指示との併用もできます。
- 手元の画像・音声をアップロードする。
- 保存済みの候補や元の素材を選び直す。

立ち絵・基準音声のタブには、保存済みの「外見の設定」「声・話し方の設定」と編集欄を表示します。元設定へ戻す操作も利用できます。直接編集と追加指示は候補の生成に使用し、承認済みの人物設定には書き戻しません。生成後も編集した設定を画面内に保持し、追加指示は送信後に空に戻します。失敗したジョブの再試行は、同じ入力・指示を使用します。

立ち絵の外見設定は、STEP3と同じ英語変換・検証・共通の全身構図指定を経てAnima用プロンプトにします。衣装や髪型などは外見の設定で編集し、構図・ポーズなどは追加指示で調整できます。候補の「設定と実際の生成指示」で元設定・編集内容・追加指示と、品質指定も含むAnimaに渡した実際のプロンプトを確認できます。基準音声では音声生成に渡した実際の指示を表示します。古い素材に実際の生成指示の記録がない場合でも、保存済みのキャラ設定は表示します。

立ち絵の画像をクリックすると拡大表示できます。「閉じる」または Escape キーで編集へ戻ります。

画像はPNG・WebP・JPEG、縦横それぞれ4096px以内、32MiB以内です。向きを補正してPNGに変換し、透明部分を保持します。背景がある画像は、その背景も表示します。

音声はPCM WAVまたはMP3、0.25〜30秒、32MiB以内です。MP3には制御サーバーのPATH上にあるFFmpegを使用します。利用できない環境ではWAVを選んでください。取り込み時にモノラルの24kHz PCM WAVに変換し、原本も保存します。

基準音声の読み上げ文には、自己紹介台詞を最初から入力しています。必要に応じて編集し、表示されている文章で生成します。空欄では生成・取り込みを実行できません。初期入力のままなら未保存の変更として扱いません。人物・タブの切り替えや生成後も、編集した文章を保持します。アップロード時は、実際に発声している本文に合わせてください。この本文と音声を一組で保持します。候補の基準音声の試聴に加え、既存の台詞を使ったサンプル生成で声を確認できます。

## 全章への反映と元の版

下書きの保存と公開版への反映は別の操作です。候補や表示位置を確認してから、調整内容を反映します。

立ち絵・表示位置だけの変更では、台本や音声を再生成しません。基準音声を変更した場合は、その人物が話す全章の台詞音声を再生成します。台詞の文面・話者・感情・シーン順は保持します。

必要な素材と章の組み立てがすべて完了してから、新しい調整版へまとめて切り替えます。生成途中や失敗時も、以前の版を鑑賞できます。失敗した工程だけを再試行し、完成済みの音声を再利用します。

章リンク・次章への移動・章別ZIP・まとめZIPは同じ調整版を参照します。旧URLと旧ZIPは保持します。閲覧位置は公開版ごとに保存するため、別の調整版へ自動的に移しません。「変更履歴・元に戻す」で公開版を選び直せます。

複数の画面から同時に編集した場合、古い下書きからの上書きを拒否します。最新の状態を読み直してから編集してください。

コード更新後は制御サーバーとワーカーを再起動してください。起動時に調整用のDBテーブルを追加し、既存の本文・素材・公開版は保持します。
