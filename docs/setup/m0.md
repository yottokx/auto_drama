## 生成・変換の検証

`scripts/m0/run_generation_checks.py` が次の順で実行する。各工程は独立プロセスとし、終了前後のGPUメモリ・計算プロセス一覧を記録する。

1. 公式Anima Diffusers版の立ち絵生成、isnet-animeでの背景除去。
2. 公式Anima Diffusers版の背景生成。
3. 公式単体チェックポイントの変換、CPUでの再ロード、生成物のハッシュ記録。
4. 変換したモデルによる立ち絵生成、背景除去。
5. Irodoriによる声デザイン、同じ参照音声からの通常・喜び・心配のクローン。
6. LLMの再実行。画像→TTS→LLMの切り替えを確認。
7. 生成画像・音声・本文からティラノの一場面を組み立て。

TTSには前回のLLM検証で生成した本文をナレーションとして使用する。表示本文と読み上げ入力を別に記録する。ティラノ本体のインストール先は変更しない。

進捗は通常のログだけを用いる。

```powershell
$run = Get-Content private/m0/latest-generation.json -Raw | ConvertFrom-Json
Get-Content -LiteralPath (Join-Path $run.run_dir 'progress.log') -Tail 20 -Wait
```

工程ごとの詳細は `image.log`、`background.log`、`conversion.log`、`converted_image.log`、`tts.log`、`llm_after_tts.log`、`tyrano_build.log`。失敗した工程で停止し、`status.json` に理由を記録する。

## 完了判定

生成処理が終了しても、画像の目視・音声試聴・ティラノでの実再生の確認が残る。`generation_completed_review_pending` はM0完了を意味しない。外部LLM APIはユーザー指定により後回しとする。

今回の技術接続は一場面の生成・再生まで確認済み。2026-09-22のユーザー試聴で、感情ごとの話し方の差と「嬉しそう」が意図どおりに出ない制約が報告された。今回の場面ではその感情を指定しないため重大な問題ではないとの判断を受け、M0は既知制約を残して完了とする。

### ユーザー試聴と残る品質上の制約

- 通常・喜び・心配では、それぞれ話し方に差がある。
- 別れを引き止める今回の本文では、喜びを指定しても嬉しそうには聞こえなかった。感情名への忠実さは未達であり、単に差が出ることと区別する。
- 台詞内容との不一致やモデルの表現能力が影響した可能性はあるが、今回の比較だけで原因をモデルの限界と断定しない。
- 今後の感情指定は台詞・場面の意図に合わせる。この場面で喜びを強制するための再調整・モデル変更はM0では行わない。

このフィードバックは感情表現への所見であり、基準声との声質一致、固有名詞の読み、すべての音声の自然さについて個別の合格報告を受けたことにはしない。これらは後続の声設定・台詞生成での品質検証へ持ち越し、今回の技術接続検証の完了を妨げる項目にはしない。記録は `review.json` の `user_audio_feedback` と `quality_follow_up`、実行状態は `status.json` の `completed_with_known_limitations` を参照。

## ティラノの再現手順

生成済み素材から再組み立てする場合は、既存結果を上書きしない新しい出力名を指定する。

```powershell
$run = Get-Content private/m0/latest-generation.json -Raw | ConvertFrom-Json
$output = Join-Path $run.run_dir ('player-' + (Get-Date -Format 'yyyyMMdd-HHmmss'))
& .\services\worker\.venv\Scripts\python.exe -I scripts/m0/build_tyrano_scene.py `
  --output-dir $output `
  --image-dir (Join-Path $run.run_dir 'image-refined') `
  --background-dir (Join-Path $run.run_dir 'background') `
  --tts-dir (Join-Path $run.run_dir 'tts') `
  --llm-dir (Join-Path $run.download_run 'llm')
```

今回確認した成果物を再び配信するには、既存のプレビューサーバーを停止してから次を実行する。

```powershell
$run = Get-Content private/m0/latest-generation.json -Raw | ConvertFrom-Json
& .\services\worker\.venv\Scripts\python.exe -I scripts/m0/serve_scene.py `
  --scene-dir (Join-Path $run.run_dir 'player-final') --port 8090
```

`http://127.0.0.1:8090/` をブラウザで開き、「はじめから」をクリックする。本文はGemmaの生成原文、ナレーションは同じ本文から作ったIrodori音声。「本文・音声」から通常・喜び・心配を比較できる。基準声は `tts/voice_design.wav`。声質の一致、ミナ・ユウなどの読み、途中切れ、感情の違いは人による試聴が必要で、信号検査の合格とは区別する。

配信は標準ライブラリのHTTPサーバーを使用し、127.0.0.1だけで待ち受ける。生成物のmanifestに登録されたファイルと、独立インストール済み `tyranoscript/tyrano/` を `/tyrano/` として配信する。エンジンは生成物やワーカーへコピーしていない。保存データはブラウザのローカルストレージで、出力先ごとのprojectIDで分離する。

Codexアプリ内ブラウザで、音声コントロールへのアクセシビリティ経由の自動クリック時にページクラッシュを2回観測した。画面上の再生ボタンへの通常クリックでは再生でき、通常20.88秒・喜び20.36秒・心配21.00秒のすべてで `currentTime=duration`、`ended=true`、メディアエラーなしを確認した。音声ファイルの破損とは認められず、自動操作方法の制限として記録する。最終プレビューのブラウザコンソールに警告・エラーはなかった。

コードの確認は `ruff check scripts/m0` とPython構文チェックに成功。`pytest` はテスト未配置のため0件であり、テスト合格数には含めない。上記の実モデル生成とブラウザ操作が今回の動作検証である。

## 画像の目視レビュー（2026-09-22）

対象記録は `private/m0/generation-20260922-104112/`。初回の `image/image.png` は顔と衣服が濃紺の単色に塗られ、立ち絵として不採用とした。モデル・seed・解像度・30 steps・CFG 4を維持し、プロンプトから `silhouette` を外して線画、肌、表情、衣服の縫い目・ボタン、正面光を明示した結果、`image-refined/image.png` では顔、肌、髪、服の陰影が描かれた。この検証済みプロンプトを `scripts/m0/image_smoke.py` の人物用既定値に反映した。正確な入力と生成条件は `image-refined/result.json` に残している。複数の語を変更した比較のため、単語一つが原因と断定はしない。

改善後の原画像と `image-refined/character.png` を目視した。緑の目、茶髪、青いコート、クリーム色のシャツ、茶色のブーツを確認でき、頭から足先まで画内に収まっている。isnet-anime処理後も顔、髪、手、コート、靴を保ち、白背景と脚の間の背景が透過されている。暗い背景で見ると髪先や衣服の輪郭に細い明るい縁が残るため、最終的な表示サイズ・背景色での見え方は引き続き確認する。今回の一枚は接続検証用素材として使用できるが、他の髪型・小物への品質は未確認。

`result.json` の `foreground_bbox` はアルファ値が1以上の画素をすべて数えるため、微小な残留アルファで画像全体の範囲になる。この値だけで人物の配置や切り抜き品質を合格判定しない。実際の人物範囲を配置に使う段階ではアルファ閾値と外れ画素の扱いを追加する。

公式Diffusers版による初回 `image/image.png` と単体チェックポイント変換後の `converted_image/image.png` はSHA256が完全一致した（`fc9b3132fe5b750b2e1996404ce7a63960831c0858439ea837d34c578716f514`）。これは今回の固定入力で変換後の生成が再現できた証拠であり、初回画像の品質合格を意味しない。背景の `background/image.png` は無人の灯台室内、夜の海、ランプ、石壁を描いており、質感と階調を確認した。これらの所見は画像工程の記録であり、M0全体の完了判定とは分ける。
